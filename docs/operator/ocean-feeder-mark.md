# Operator: znacznik ocean feeder / short-sea

Katalog HITL dla znacznika feeder / short-sea / inne.
Zapisujesz kod, `feeder_kind` i `source_ref`. To nie jest live feeder schedule ani TEU.

`amount`, `teu` i `score` są odrzucane. Zmiana wiersza = nowy rekord (brak UPDATE).
Obok `ocean_alliance_mark` — tu tylko feeder/short-sea, nie alliance live.

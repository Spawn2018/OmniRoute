# Runda załadowcy (BR6.2 leftover)

Operator zapisuje katalogową rundę: kod, `round_kind`
(`first` / `second` / `final` / `other`) i `source_ref`. To dane HITL,
nie Alpega i nie silnik like-for-like.

Nie liczy kwot. Marża nadal tylko na `charge`.
Like-for-like i FK zostają leftover.

Ścieżka UI: `/shipper-round-marks`.

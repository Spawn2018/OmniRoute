# Brama L3 (`l3_gate_mark`)

Katalog HITL checklisty przed poziomem autonomii 3: źródło prawdy (sot),
właściciel (owner), wyjątek (exception), rollback, promień wybuchu (blast).

Nie włącza zapisu AI. Nie zmienia `autonomy_level`. Pozycje wpisuje operator.

Ścieżka: `/l3-gate-marks`. SOP agenta: [agent-l3-sop.md](agent-l3-sop.md).

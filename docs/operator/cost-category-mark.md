# Cost category (AI7.0 leftover)

Operator zapisuje katalogowy znacznik kategorii kosztu: kod, `category_kind`
(`direct` / `shared` / `allocated` / `overhead` / `capital` / `risk` / `other`)
i `source_ref`. To dane HITL PDF §13j, nie allocation SQL i nie TCM.

Nie liczy kwot. Marża nadal tylko na `charge`.

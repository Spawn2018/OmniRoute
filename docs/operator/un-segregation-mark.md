# Operator: segregacja UN

Katalog HITL dla tunelu ADR i segregacji numerów UN
(`tunnel` / `segregation` / `compat` / `other`).
Zapisujesz kod, `segregate_kind` i `source_ref`. To nie jest solver OR
ani plan załadunku.

`amount`, `axle` i `score` są odrzucane. Zmiana wiersza = nowy rekord (brak UPDATE).

# Urządzenie telematyczne (BR2.1)

Operator zapisuje katalogowe urządzenie: kod, `device_kind`
(`tracker` / `fault` / `other`) i `source_ref`. To dane HITL,
nie parowanie z pojazdem i nie live poll.

Nie liczy kwot. Marża nadal tylko na `charge`.
Parowanie z `resource` zostaje leftover.

Ścieżka UI: `/telematics-devices`.

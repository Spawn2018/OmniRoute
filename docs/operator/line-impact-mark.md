# Operator: znacznik skutku linii

Katalog HITL dla znacznika skutku linii / zakładu / SKU / inne.
Zapisujesz kod, `impact_kind` i `source_ref`. To nie jest silnik SQL line impact ani EBITDA.

`amount`, `score` i `ebitda` są odrzucane. Zmiana wiersza = nowy rekord (brak UPDATE).
Bez plant live feed — tylko znacznik gdy dane.

# Wynik interwencji (CI7)

Operator zapisuje katalogowy wynik interwencji: kod, `result_kind`
(`contained` / `rerouted` / `claimed` / `other`) i `source_ref`. To dane HITL,
nie SQL saved i nie automatyczna suma oszczędności.

Nie liczy kwot. Marża nadal tylko na `charge`.

Ścieżka UI: `/intervention-outcomes`.

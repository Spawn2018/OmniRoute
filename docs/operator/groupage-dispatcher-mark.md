# Dyspozytor drobnicy (BR3.2)

Operator zapisuje katalogowy stance dyspozytora: kod, `dispatcher_kind`
(`line` / `hub` / `cutoff` / `consol` / `other`) i `source_ref`. To dane HITL,
nie silnik hubów i nie konsolidacja liczona.

Nie liczy kwot. Marża nadal tylko na `charge`. Linia drobnicy i cennik zostają
osobnymi katalogami.

Ścieżka UI: `/groupage-dispatcher-marks`.

# Operator: znacznik pallet-pool

Katalog HITL dla rodzaju pallet-poolu (Chep / LPR / EPAL).
Zapisujesz kod, rodzaj i `source_ref`. To nie uruchamia solvera OR ani depozyt.

Obok `pallet_balance` (osie/tunel) — tu tylko znacznik strategii packingu.

`amount` i bajty są odrzucane. Zmiana wiersza = nowy rekord (brak UPDATE).

# Zezwolenie OOG (BR4.1)

Operator zapisuje katalogowy stance: kod, `permit_kind`
(`permit` / `pilot` / `route` / `other`) i `source_ref`. To dane HITL,
nie metry ładunku i nie wniosek do urzędu.

Nie liczy kwot. Marża nadal tylko na `charge`. Osie i lashing zostają
w osobnym katalogu G5 `oog_mark`.

Ścieżka UI: `/oog-permit-marks`.

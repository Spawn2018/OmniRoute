# Operator: stance slotu

Katalog HITL dla postawy wobec slotu terminalu
(`capability` / `non_guarantee` / `other`).
Zapisujesz kod, `stance_kind` i `source_ref`. To nie jest rezerwacja
ani gwarancja prawna z API T8.

`amount`, `margin` i `confirmed` są odrzucane. Zmiana wiersza = nowy rekord (brak UPDATE).

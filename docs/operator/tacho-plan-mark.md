# Tacho w planie (BR3.3)

Operator zapisuje katalogowe ograniczenie: kod, `constraint_kind`
(`plan` / `window` / `rest` / `other`) i `source_ref`. To dane HITL,
nie odczyt karty i nie liczenie godzin.

Nie liczy kwot. Marża nadal tylko na `charge`. Biuro tachografu zostaje
w osobnym katalogu office/card/ddd.

Ścieżka UI: `/tacho-plan-marks`.

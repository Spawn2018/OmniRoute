# Kandydat dopasowania FV (F10)

Operator zapisuje katalogowy znacznik stancji kandydata dopasowania FV: kod, `candidate_kind`
(`en` / `uss` / `epo` / `other`) i `source_ref`. To dane HITL,
nie live ranking SQL i nie auto-link.

Nie liczy kwot. Marza nadal tylko na `charge`.

Sciezka UI: `/invoice-match-candidates`.

# Wymog dokumentow relacji (C8)

Operator zapisuje katalogowy znacznik stancji wymogu dokumentow relacji: kod, `relation_kind`
(`en` / `uss` / `epo` / `other`) i `source_ref`. To dane HITL,
nie live 409 na shipment i nie blocks_create.

Nie liczy kwot. Marza nadal tylko na `charge`.

Sciezka UI: `/relation-document-requirements`.

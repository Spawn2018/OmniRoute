# Operator: znacznik chassis / trailer

Katalog HITL dla znacznika chassis / trailer / inne.
Zapisujesz kod, `chassis_kind` i `source_ref`. To nie jest live chassis pool ani TEU.

`amount`, `teu` i `score` są odrzucane. Zmiana wiersza = nowy rekord (brak UPDATE).
Obok `empty_depot_mark` — tu tylko chassis/trailer, nie depot live / yard / WMS.

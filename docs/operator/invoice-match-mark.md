# Dopasowanie FV zakupu (F10 leftover)

Operator zapisuje katalogowy znacznik stancji match: kod, `match_kind`
(`candidate` / `rank` / `allocate` / `other`) i `source_ref`. To dane HITL,
nie ranking SQL, nie allocation i nie auto-link do `charge`.

Nie liczy kwot. Marża nadal tylko na `charge`.

Ścieżka UI: `/invoice-match-marks`.

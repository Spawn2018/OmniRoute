# Alokacja FV zakupu (F10 leftover)

Operator zapisuje katalogowy znacznik stancji alokacji: kod, `alloc_kind`
(`line` / `header` / `batch` / `other`) i `source_ref`. To dane HITL,
nie allocation z kwotą, nie ranking SQL i nie auto-link do `charge`.

Nie liczy kwot. Marża nadal tylko na `charge`.

Ścieżka UI: `/invoice-alloc-marks`.

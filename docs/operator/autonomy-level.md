# Operator: poziom autonomii

Otwarty słownik poziomów autonomii AI.
Zapisujesz kod poziomu — nowy poziom to nowy wiersz, bez czekania
na wydanie ani zmianę listy w bazie.

Nie ma tu zamkniętej listy sześciu stopni z taksonomii.
Nie wiążesz poziomu z konkretnym klientem.
`amount` i `margin` są odrzucane. Zmiana wiersza = nowy rekord.

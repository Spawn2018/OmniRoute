# Przekazanie zmiany SBAR (N11)

Operator zapisuje znacznik przekazania per strona: kod, `sbar_kind`
(`situation` / `background` / `assessment` / `recommendation` / `other`)
i `source_ref`. To dana HITL, nie drugi czat i nie auto-wypelnianie z tablicy.

Nie liczy kwot. Marza nadal tylko na `charge`.

Sciezka UI: `/handover-sbar-marks`.

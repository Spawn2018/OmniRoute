# Katalogi zapisu

Wpisujesz rekord z pochodzeniem. Nie ma luźnego stringa zamiast kodu. Kwota to Decimal z walutą. Model językowy tych ekranów nie obsługuje.

Ekrany, które **zapisują** (INSERT/upsert), nie tablice-odczyty:

- kody opłat, kody HS/CN, numery UN (tunel ADR + grupa SG), sieci — kod / nazwa / aliasy
- stawki kupna — niemutowalne, `source_ref`; zmiana = nowy wiersz
- opłaty — kupno i sprzedaż na jednym wierszu; marża z pary, nie z arkusza. Przy zapisie podajesz pochodzenie (`source_ref`: `tenant:manual`, `fixture://charge/…`). Stare wiersze mogą nie mieć pochodzenia. Porównanie na wycenie zapisuje `tenant:manual:comparison`.
- kurs NBP, extra portowe, oferty kanału — katalog, nie live HTTP. Na extra portowych „Dopasuj warunek” pokazuje wiersze, których `applies_when` jest dokładnie taki jak wpisałeś. To nie dopisuje opłaty ani marży.
- porty, strefy taryfowe, terminale — UN/LOCODE / zakres pocztowy / ISPS
- sieci `/networks` — katalog sieci oraz ręczny członek (`member_code` + nazwa + `party_id` kontrahenta) w wybranej sieci. Stary członek może nie mieć kontrahenta. „Zapisz zapytanie” dopisuje `carrier_inquiry` (`draft`). „Zapisz paczkę” — 1/wielu/wszyscy, status `queued`, opcjonalna trasa. Kwota tylko przy odpowiedzi. Top N z rankingu `answered` + „Zapisz szkice” (`mail_draft` / `carrier_inquiry`). Filtr kraju ISO na członkach (`party.country_code`). Data ciszy (`no_reply_after`) + lista overdue; notice `no_reply` tylko ręcznie. Nie U4. Nie portal. Nie live HTTP.
- ustawienie `default_currency`, `quotation_number_prefix`, `quotation_print_template`, `inquiry_default_n` (1–20), `lane_scorecard_window_days` (1–365), `fx_rate_basis` / `fx_rate_offset_days` (`0`/`-1`) / `fx_rate_table` — allowlista. Kalendarz (`organization_calendar`; `is_working_day` w SQL). Karta lane na `/party-scorecards`. Nie sekret. Nie mnożenie kursem.
- SOP klienta — treść + akceptacja procedury. Checkbox „Blokuj auto” zabrania automatu; świadomy `mailto:` i tak wymaga kliknięcia. Flaga widać przy szkicu na `/ai`. Nie generator zadań.
- poczta `/mail` — `inbound_message` z `fixture://` / `synth://` albo ingest `graph://` / `imap://` + `external_id` (ten sam id = ten sam wiersz). Grupowanie `group_by`: party / country / status, default party. Nie wątek. Nie live skrzynka. Nie send.
- outbox `/outbox` — zdarzenie `inbound_message_saved` po poczcie, `task_template_saved` po szablonie. Ten sam subject = ten sam wiersz. Nie Temporal. Nie dispatch.
- zlecenie `/shipments` — zapis `shipment` z wyceny, opcjonalny twardy numer `shipment_ref` HITL (`omni://shipment/…` / `fixture://shipment-ref/…`, nie QR, nie PDF, nie generator GD), opcjonalny rodzic `parent_shipment_id` + `relation_kind` (nie SQL marży), strony (`shipment_stakeholder`; `party_id` wymagane) i instrukcji (`booking_instruction`; status dane, nie S21) oraz punktu (`stop`; miejsce ze słownika, strefa IANA, dwa ETA HITL, opcjonalny `stop_group_code`, opcjonalny `notes_for_driver`, opcjonalny `weight_kg`, opcjonalny `quantity`, opcjonalny `packaging_code`, opcjonalny `seal_in`, opcjonalny `seal_out`, opcjonalny `appointment_ref`, opcjonalny `waiting_free_minutes`, opcjonalny `waiting_started_at`, opcjonalny `pod_quality`, nie GPS, nie mapa) i zasobu (`resource`; pojazd/kierowca/naczepa; także `/fleet`) oraz przesyłki (`consignment`; `/consignments`; N na zlecenie, nie paczka) oraz przejazdu (`trip`; snapshot `expected_buy` przy w drodze, opcjonalny `driver2_id`, opcjonalny `route_label`, opcjonalny `planned_distance_km`, opcjonalny `actual_distance_km`, opcjonalny `subcontractor_party_id`, nie GPS, nie wariancja) i kontenera (`container`; ISO 6346, opcjonalny `seal_no_1`/`seal_no_2`/`seal_no_3`, opcjonalny `vessel_name`/`voyage_no`, opcjonalny `remarks`, opcjonalny `cargo_description`, opcjonalny `packaging_code`, opcjonalny `ref_1`, opcjonalny `ref_2`, opcjonalny `ref_3`, opcjonalny `ref_4`, opcjonalny `ref_5`, opcjonalny `reefer` (flaga, nie temperatura), opcjonalny `pickup_terminal` (tekst, nie FK), opcjonalny `return_terminal` (tekst, nie FK), opcjonalny `bl_kind` (`original`/`seawaybill`/`telex`/`express`, nie HBL), opcjonalny `free_time_origin_h` (godziny origin, nie odliczanie), opcjonalny `free_time_dest_h` (godziny destination, nie odliczanie), opcjonalny `si_cutoff_at` (ISO ze strefą, nie live HTTP), opcjonalny `ams_cutoff_at` (ISO ze strefą, nie live HTTP), opcjonalny `cy_cutoff_at` (ISO ze strefą, nie live HTTP), opcjonalny `cfs_cutoff_at` (ISO ze strefą, nie live HTTP), opcjonalny `vgm_kg` (Decimal, nie float), opcjonalny `vgm_method` (`method1`/`method2`), opcjonalny `vgm_cutoff_at` (ISO ze strefą, nie live HTTP), opcjonalny `last_survey_at` (ISO ze strefą, nie live HTTP), opcjonalny `booking_no` (nie S21, nie live HTTP), opcjonalny `carrier_party_id` (UUID armatora, nie PIN, nie live HTTP), opcjonalny `shipment_leg_id` (UUID odcinka, nie PIN, nie live HTTP), nie kalkulator kg, nie PIN, nie booking). Na `/quotations`: przeniesienie Incoterms (`field_carry_forward`; zmiana = nowy wiersz), checklista (`document_checklist_rule`; `blocks_dispatch` = dana, nie C8), macierz (`incoterm_responsibility`; seed Omni, nie cytat ICC) i adresat (`document_dispatch_rule`; rola, nie send).

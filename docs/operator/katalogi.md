# Katalogi zapisu

Wpisujesz rekord z pochodzeniem. Nie ma luźnego stringa zamiast kodu. Kwota to Decimal z walutą. Model językowy tych ekranów nie obsługuje.

Ekrany, które **zapisują** (INSERT/upsert), nie tablice-odczyty:

- kody opłat, kody HS/CN, numery UN, sieci — kod / nazwa / aliasy
- stawki kupna — niemutowalne, `source_ref`; zmiana = nowy wiersz
- opłaty — kupno i sprzedaż na jednym wierszu; marża z pary, nie z arkusza. Przy zapisie podajesz pochodzenie (`source_ref`: `tenant:manual`, `fixture://charge/…`). Stare wiersze mogą nie mieć pochodzenia. Porównanie na wycenie zapisuje `tenant:manual:comparison`.
- kurs NBP, extra portowe, oferty kanału — katalog, nie live HTTP. Na extra portowych „Dopasuj warunek” pokazuje wiersze, których `applies_when` jest dokładnie taki jak wpisałeś. To nie dopisuje opłaty ani marży.
- porty, strefy taryfowe, terminale — UN/LOCODE / zakres pocztowy / ISPS
- sieci `/networks` — katalog sieci oraz ręczny członek (`member_code` + nazwa + `party_id` kontrahenta) w wybranej sieci. Stary członek może nie mieć kontrahenta. „Zapisz zapytanie” dopisuje `carrier_inquiry` (`draft`). „Zapisz paczkę” — 1/wielu/wszyscy, status `queued`, opcjonalna trasa. Kwota tylko przy odpowiedzi. Top N z rankingu `answered` + „Zapisz szkice” (`mail_draft` / `carrier_inquiry`). Filtr kraju ISO na członkach (`party.country_code`). Data ciszy (`no_reply_after`) + lista overdue; notice `no_reply` tylko ręcznie. Nie U4. Nie portal. Nie live HTTP.
- ustawienie `default_currency`, `quotation_number_prefix`, `quotation_print_template`, `inquiry_default_n` (1–20), `lane_scorecard_window_days` (1–365) — allowlista. Kalendarz (`organization_calendar`; `is_working_day` w SQL). Karta lane na `/party-scorecards`. Nie sekret.
- SOP klienta — treść + akceptacja procedury. Checkbox „Blokuj auto” zabrania automatu; świadomy `mailto:` i tak wymaga kliknięcia. Flaga widać przy szkicu na `/ai`. Nie generator zadań.
- poczta `/mail` — `inbound_message` z `fixture://` / `synth://` albo ingest `graph://` / `imap://` + `external_id` (ten sam id = ten sam wiersz). Grupowanie `group_by`: party / country / status, default party. Nie wątek. Nie live skrzynka. Nie send.
- outbox `/outbox` — zdarzenie `inbound_message_saved` po zapisie wiadomości. Ten sam subject = ten sam wiersz. Nie Temporal. Nie dispatch.
- zlecenie `/shipments` — zapis `shipment` z wyceny, strony (`shipment_stakeholder`; `party_id` wymagane) i instrukcji (`booking_instruction`; status dane, nie S21) oraz punktu (`stop`; miejsce ze słownika, strefa IANA, nie mapa) i zasobu (`resource`; pojazd/kierowca/naczepa) oraz przejazdu (`trip`; snapshot `expected_buy` przy w drodze, nie km, nie wariancja) i kontenera (`container`; ISO 6346, nie VGM). Na `/quotations`: przeniesienie Incoterms (`field_carry_forward`; zmiana = nowy wiersz), checklista (`document_checklist_rule`; `blocks_dispatch` = dana, nie C8), macierz (`incoterm_responsibility`; seed Omni, nie cytat ICC) i adresat (`document_dispatch_rule`; rola, nie send). How-to: [zlecenie.md](zlecenie.md). Nie tracking. Nie druga marża.
- tracking `/tracking` — zapis `tracking_event` na zleceniu. How-to: [tracking.md](tracking.md). Nie mapa. Nie AIS. Czas podaje operator.
- dokumenty `/shipment-documents` — zapis `shipment_document` na zleceniu. How-to: [dokument-zlecenia.md](dokument-zlecenia.md). Nie bajty. Nie wydruk. Skan zostaje na ekstrakcji.
- wyjątki `/exceptions`, reklamacje `/claims`, oszustwo `/fraud` — `operational_exception` / `cargo_claim` / `fraud_flag`. How-to: [wyjatek.md](wyjatek.md), [reklamacja.md](reklamacja.md), [oszustwo.md](oszustwo.md). Nie mapa. Nie scoring.
- EDI `/edi` — zapis `edi_message` na zleceniu. How-to: [edi.md](edi.md). Nie parser. Nie live HTTP. Oferta kanału zostaje na `/channel-quotes`.
- faktury `/invoices` — zapis `sales_invoice` na zleceniu i numer sesji (`ksef_ref`). How-to: [faktura.md](faktura.md). Zbiorcza: dodatkowe zlecenie na tej samej fakturze. How-to: [zbiorcza-faktura.md](zbiorcza-faktura.md). Nie live HTTP. Nie kwota na tym wierszu. Sprzedaż zostaje na `/charges`.
- rozliczenie `/quote-invoices` — zapis pary wycena+faktura. How-to: [rozliczenie.md](rozliczenie.md). Nie kwota na tym wierszu. Nie odejmowanie. Sprzedaż zostaje na `/charges`.
- płatności `/payments` — zapis pary faktura+rachunek. How-to: [platnosc.md](platnosc.md). Nie kwota na tym wierszu. Nie SEPA. Sprzedaż zostaje na `/charges`. Rachunek zostaje na `/parties`.
- koszt pieniądza `/money-cost` — zapis pary płatność+kurs NBP. How-to: [koszt-pieniadza.md](koszt-pieniadza.md). Nie kwota na tym wierszu. Nie mnożenie. Kupno zostaje na `/charges`.
- różnice kursowe `/fx-differences` — zapis pary wycena+kurs NBP. How-to: [roznica-kursowa.md](roznica-kursowa.md). Nie kwota na tym wierszu. Nie przeliczenie. Sprzedaż zostaje na `/charges`.
- przepływy `/cashflows` — zapis pary wycena+płatność. How-to: [przeplywy.md](przeplywy.md). Nie kwota na tym wierszu. Nie odejmowanie. Sprzedaż zostaje na `/charges`.
- koszt obsługi `/cost-to-serve` — zapis pary SOP+wycena. How-to: [koszt-obslugi.md](koszt-obslugi.md). Nie kwota na tym wierszu. Nie suma. Sprzedaż zostaje na `/charges`.
- księgowość `/bookkeeping` — zapis pary opłata+faktura. How-to: [ksiegowosc.md](ksiegowosc.md). Nie kwota na tym wierszu. Nie JPK. Sprzedaż zostaje na `/charges`.
- RODO `/gdpr` — wniosek `access`/`erasure` na koncie tenanta. How-to: [rodo.md](rodo.md). Wypełnienie erasure to tombstone emailu, nie `DELETE` wiersza. Nie DPIA.
- droga `/road` — zapis odcinka `shipment_leg` (`leg_kind=road`) na zleceniu. How-to: [odcinek.md](odcinek.md). Start i koniec to strefa albo adres, nie port. Nie TMS. Nie mapa.
- kolej `/rail`, `/china-rail`, `/lcl`, `/air`; linia `/groupage`; cennik `/groupage-tariffs`; paczka `/shipment-packages`; awizacja `/dock-appointments`; pobranie `/cod`; konosament `/ocean-bills`; palety `/pallet-balances`; szablon `/document-templates`; karta `/rate-cards`; szablon opłat `/charge-templates`; indeks `/fuel-indexes`; dopłata `/local-charges`; przetarg `/tenders`, `/tender-lots`, `/tender-lanes`, `/tender-data-rooms`, `/tender-matrix-cells`, `/tender-playbooks`, `/tender-win-losses`, `/tender-consortium-members`, `/tender-rfp-intakes`, `/tender-rounds`, `/tender-quotes` — nogi UN/LOCODE jak wcześniej; katalog `groupage_line`; próg wagi Decimal na strefie; skan QR Omni; okno TIME na `stop` magazynu; znacznik COD bez kwoty; HBL/MBL bez PDF; saldo Chep/LPR; layout jako dane; warunek `applies_when` + Decimal; kolekcja kodów + daty; FSC/BAF/CAF; THC/ISPS Decimal; nagłówek sell/buy; kod partii; para UN/LOCODE; numer rundy; NDA signed; komórka Decimal z P; teza playbooka; werdykt win/loss; fotel konsorcjum; przyjęcie RFP HITL; ważność + limit orderów. - wieża `/watchtower` — wyjątki + pending S11 + odczyt `mail_draft`. How-to: [wieza.md](wieza.md). Zapis szkicu na `/ai`. Liczniki tablicy + leniwy panel mapy, nie leaflet.
- decyzje `/decisions` — pending na `subject_id`; Akceptuj, Zmień albo Odrzuć z `lock_version`. Dwa okna, dwa Akceptuj: drugi dostaje konflikt. Nie accept extractu. Nie send.
- powiadomienia `/notifications` — zapisany inbox `unread`/`read` z `source_ref`. Tablica pending HITL/wycen zostaje odczytem (filtr: wszystkie / HITL / wyceny). Nie send.
- szkic maila `/ai` — `mail_draft` obok extractu; na `/networks` szkic zapytania (`carrier_inquiry`). Werdykt na `/decisions`. Po Akceptuj: „Wyślij w kliencie” zapisuje `sent` i daje `mailto:`. SOP `blocks_auto` nie blokuje tego kliknięcia. Nie czat. Nie Graph HTTP. Nie accept extractu.

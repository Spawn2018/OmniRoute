# Kabotaż (EXP2.11)

Operator zapisuje etykietę związaną z kabotażem: licznik, powrót kierowcy, powrót
pojazdu albo inną. To katalog HITL, nie silnik zgodności z dyrektywą.

Wiersz ma `mark_code`, `cabotage_kind` i `source_ref`. OmniRoute nie liczy limitów
kabotażu, nie śledzi RTPD i nie łączy znacznika z tachografem.

Live cabotage / prawo per kraj zostają leftoverem poza tym plasterem.

# Intencja klonu zlecenia (N9)

Operator zapisuje intencje klonu per strona: kod, `clone_kind`
(`last_similar` / `manual_pick` / `other`) i `source_ref`. To dana HITL,
nie kopiowanie wierszy zlecenia ani drugi SoR.

Osobno: `/clone-carry-marks` — stance `carry` / `held` / `skip` / `other`,
czy przy klonie przenieść allowlistę U1. Nadal nie auto-copy i nie similar SQL.

Nie liczy kwot. Marza nadal tylko na `charge`.

Sciezka UI: `/shipment-clone-marks` · `/clone-carry-marks`.

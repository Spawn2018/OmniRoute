# Combined transport (EXP2.12)

Operator zapisuje etykietę reżimu: transport kombinowany, Mobility Package,
piggyback/Huckepack albo inny. To katalog HITL, nie silnik prawny.

Każdy wiersz ma `mark_code`, `regime_kind` i `source_ref`. System nie ocenia
zgodności z dyrektywą, nie rozwiązuje przeładunku i nie tworzy charge.

Live combined transport / prawo per kraj zostają leftoverem poza tym plasterem.

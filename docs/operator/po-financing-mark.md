# Finansowanie zamówienia (BR5.1)

Operator zapisuje katalogowy znacznik stance finansowania zamówienia Trade-Tech:
kod, `financing_kind` (`po` / `release` / `advance` / `other`) i `source_ref`. To dane
HITL, nie wycena zapasu BR1.2 i nie live HTTP partnera.

Nie liczy kwot. Marża nadal tylko na `charge`. Nagłówek PO CT1 i konektor faktoringu
471.0 zostają bez kleju do tego katalogu.

Ścieżka UI: `/po-financing-marks`.

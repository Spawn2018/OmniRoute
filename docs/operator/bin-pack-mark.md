# Operator: znacznik bin-pack

Katalog HITL dla rodzaju bin-packu (objętość / masa / mieszany).
Zapisujesz kod, rodzaj i `source_ref`. To nie uruchamia solvera OR ani LLM-VRP.

Obok `load_plan_mark` (osie/tunel) — tu tylko znacznik strategii packingu.

`amount` i bajty są odrzucane. Zmiana wiersza = nowy rekord (brak UPDATE).

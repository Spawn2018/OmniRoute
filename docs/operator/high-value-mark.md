# Operator: protokół high-value

Katalog HITL dla protokołu ładunku wysokiej wartości (`high_value` / `protocol` / `other`).
Zapisujesz kod, `protocol_kind` i `source_ref`. To nie jest `cargo_value` ani ubezpieczenie.

`amount`, `margin`, `score` i `cargo_value` są odrzucane. Zmiana wiersza = nowy rekord (brak UPDATE).

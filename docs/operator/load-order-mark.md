# Kolejność załadunku (BR3.1)

Operator zapisuje katalogową kolejność: kod, `order_kind`
(`sequence` / `stack` / `door` / `other`) i `source_ref`. To dane HITL,
nie solver i nie wymiary.

Nie liczy kwot. Marża nadal tylko na `charge`. Osie i tunel zostają
w osobnym katalogu planu załadunku.

Ścieżka UI: `/load-order-marks`.

# Checklista LC (G3)

Operator zapisuje katalogową checklistę akredytywy: kod, `status_kind`
(`open` / `presented` / `closed` / `other`) i `source_ref`. To dane HITL,
nie bank stakeholder i nie termin `presentation_due`.

Nie liczy kwot. Marża nadal tylko na `charge`.

Ścieżka UI: `/lc-checklists`.

# Operator: miejsce nazwane

Katalog HITL dla miejsca nazwanego Incoterms wraz z wersją reguł
(`2020` albo `2010`).
Zapisujesz kod, tekst miejsca, wersję i `source_ref`. To nie jest cytat ICC
ani zmiana pól na wycenie.

`amount`, `margin` i `icc_quote` są odrzucane. Zmiana wiersza = nowy rekord (brak UPDATE).

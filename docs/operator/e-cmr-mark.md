# Operator: znacznik e-cmr

Katalog HITL dla rodzaju e-cmru (ecmr / efti / paper).
Zapisujesz kod, rodzaj i `source_ref`. To nie uruchamia solvera OR ani eFTI filer.

Obok `filing_scheme_mark` (osie/tunel) — tu tylko znacznik strategii packingu.

`amount` i bajty są odrzucane. Zmiana wiersza = nowy rekord (brak UPDATE).

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z kolejki O0):** kolumna `party_id` na **istniejącym** `network_member`. W bazie **nullable** (stare człony bez zmyślonego kontrahenta). FK złożone tenanta `(organization_id, party_id) → party`. Nowy INSERT **wymaga** `party_id`. Job na tym samym `/networks`. API składa: odczyt `party`, zapis członka. Serwis sieci nie importuje `parties`. Zero nowej tabeli. Zero rankingu.

**Łowca:** ISTNIEJE 82.0 `network_member` + `create_member` + `/networks` + `can_manage_networks`. ISTNIEJE `party` z `uq` org+id (wzorzec FK jak `shipment`). BRAK `network_member.party_id`. PODOBNE: `terminal.operator_party_id` (nullable, bez importu serwisu parties); `shipment.party_id` (NOT NULL od początku). Nie duplikować `legal_name` z karty kontrahenta.

- Backfill / `NOT NULL` na starych wierszach.
- Ranking, znaczki, batch inquiry (O1–O3) i 409 „powiąż” przy wysyłce — nie ma jeszcze rankingu.

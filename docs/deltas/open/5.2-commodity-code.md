# Plaster 5.2 · M-09 Kody towarowe (`commodity_code`)

**Spec źródłowa:** [docs/spec/commodity-code.md](../../spec/commodity-code.md)  
**Zależy od:** 0.3 RLS · 0.4 OpenFGA · 0.6 DataTableShell · wzorzec katalogu 1.0 `charge_code`

**Status:** Delta zaakceptowana `/noc` 2026-09-01. Wolno `/plaster`. Nie Q5.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z kolejki Q4):** jeden katalog per tenant — tabela `commodity_code` (kod HS/CN jako token + nazwa + aliasy + `source_ref`). `resolve` po kodzie albo aliasie. UI `/commodity-codes`. Żywy ID **M-09** (brak kolizji z M-07 `rate_line` / M-08 `charge`).

**Odrzucone:**

- Podpięcie kodu do `quotation` / `rate_line` w tym plastrze — kolejka Q4 to katalog, nie drugi wymiar wyceny.
- Towary niebezpieczne (Q6, archiwum M-08) — inny moduł, żywe M-08 = `charge`.
- Seed światowej taryfy HS/TARIC i live HTTP do UE — jak 4.0 bez 670k na starcie; operator wpisuje kody, których używa.
- Druga tabela aliasów, pgvector, scoring towaru.

## Zakres

Katalog kodu towarowego per tenant. Lista, dodanie, `resolve`. RLS FORCE. OpenFGA `can_manage_commodity_codes` = member.

## Poza zakresem

Q5–Q6 · `quotation` / `rate_line` czytające `commodity_code` · IMDG / klasy ADN · TARIC live · Auth0 · M-02 · portale · Exit Wave FE · leftovery UI ADR-0003 · ExtractionService→katalog towarów.

## Ustalenia

- Żywy ID: **M-09**. Token w kodzie: `commodity_code` (GLOSSARY: kod towarowy). Nie `hs_code` w nazwie tabeli — CN bywa 8 znaków, HS 6; to jeden katalog.
- `code`: 4–10 cyfr po normalizacji (HS-6 albo CN-8 albo krajowe 10). Bez liter. Puste / nie-cyfry = `InvalidCommodityCode`.
- `resolve(token)`: dokładne, po `code` albo aliasie; nieznany = `UnknownCommodityCode`. Nie luźna nazwa.
- Aliasy na wierszu (`text[]`), nie osobna tabela — jak `charge_code`.
- `source_ref` obowiązkowy; ręczny wpis = `tenant:manual`.
- Unikat `(organization_id, code)`.
- OpenFGA: nowa relacja `can_manage_commodity_codes` = `member`. Brak tuple na pojedynczy kod.
- RLS FORCE + test izolacji dwóch organizacji.
- Job operatora: `/commodity-codes` — DataTableShell, dodanie, pole resolve.
- import-linter: `app.services.commodity_codes` jako niezależny BC. Extraction nie importuje katalogu.
- Migracja `017_commodity_code_rls` (w górę i w dół).
- Kwoty nie mieszkają na katalogu. LLM nie liczy.

## Schemat

`commodity_code`: `id`, `organization_id`, `code` (4–10 cyfr), `name`, `aliases text[]`, `source_ref`, timestamps.

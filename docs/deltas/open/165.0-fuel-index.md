## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z P3):** jedna tabela `fuel_index` per tenant — **katalog indeksu FSC/BAF/CAF jako dane**, obok `nbp_rate`, nie mnożenie w SQL na `charge`. Wiersz = `index_kind` (`fsc` | `baf` | `caf`) + `published_on` (`DATE`) + `index_value` (`Numeric(14,4)` > 0, Decimal, nie waluta) + `source_ref` (`tenant:manual` albo `fixture://fuel-index/…`). `index_kind` spoza allowlisty → 400 (detail zawiera `rodzaj`). Zła data → 400 (detail zawiera `data`). `index_value` ≤ 0 / float / bool → 400 (detail zawiera `indeks`). GET listy SQL. Serwis indeksu nie importuje nbp_rates / charges / rate_cards / groupage_tariffs. Zero waluty na tym wierszu (to nie kurs NBP i nie marża). UI `/fuel-indexes`. `SHIPPED_CHARGE_ROUTES["165.0"]` = `/fuel-indexes`. OpenFGA: `can_manage_fuel_indexes`. Migracja `105_fuel_index`. Marża zostaje na `charge`.

**Łowca:** ISTNIEJE `nbp_rate` — kurs średni tabeli A NBP (`mid` + ISO); **nie** rozszerzamy o FSC. ISTNIEJE `rate_card` — warunek + kwota pieniężna; **nie** rozszerzamy. ISTNIEJE `groupage_tariff` — leftover FSC w D5; **nie** rozszerzamy. ISTNIEJE `charge` — jedyna marża. BRAK `fuel_index`. BRAK `/fuel-indexes`.

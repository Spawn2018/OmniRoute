## Wybrane / odrzucone / dlaczego

**Wybrane:** sieć prawna w tym plasterze = **zapis numeru sesji**, nie live bramka MF. Operator wpisuje `ksef_ref`, który już ma (`fixture://ksef/` albo `ksef://`). Serwis ustawia `ksef_ref` + `ksef_noted_at` na istniejącym `sales_invoice`. Wzorzec jak S27 (`sanctions_list_ref`). Zero nowej tabeli. Zero XML. Kwoty zostają na `charge`.

**Łowca:** ISTNIEJE 96.0 `sales_invoice` + `/invoices` + `can_manage_sales_invoices`. BRAK kolumny KSeF / XML / FA(3). PODOBNE: 89.0 `sanctions_list_ref`; 88.0 URI załącznika. Dwa joby (faktura vs sesja) = ten sam ekran, druga akcja.

**Odrzucone:**

- Live HTTP do MF / KSeF — teatr bez umowy i bez kasy klucza tenanta (S21 ten sam zakaz).
- Budowa XML / FA(3).
- Nowa tabela sesji / kolejek.
- Auto-wysyłka.
- Kwota / marża na kolumnie.
- LLM piszący fakturę.
- F9.1.

## Zakres

1. Migracja `055_sales_invoice_ksef_ref` (po `054_sales_invoice_rls`): `ksef_ref` TEXT NULL, `ksef_noted_at` timestamptz NULL na `sales_invoice`. RLS z 054.
2. `POST /sales-invoices/{id}/note-ksef` — `{ksef_ref}`. OpenFGA `can_manage_sales_invoices`. `SalesInvoiceService`. Nieznana faktura → 404. Zły prefix / pusty ref → 400.
3. UI `/invoices`: „Zapisz numer sesji”. `SHIPPED_CHARGE_ROUTES["97.0"]` = `/invoices`. Asercja 96.0 bez `xml` / `fa3` / `CatalogCreateForm` zostaje; zakaz samego `ksef` na tablicy **schodzi** (pole `ksef_ref`).
4. `just api-types`. How-to `docs/operator/faktura.md`.

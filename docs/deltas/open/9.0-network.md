**Spec źródłowa:** [docs/spec/network.md](../../spec/network.md)  
**Zależy od:** 0.3 RLS · 0.4 OpenFGA · 0.6 DataTableShell · wzorzec katalogu 5.2 `commodity_code` · Aneks 8 (obiekty, nie pipeline)

**Status:** Otwarty `/noc` 2026-09-01. Nie Fala 8. Nie M-62 graf.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z M-12):** jeden katalog per tenant — tabela `network` (token kodu + nazwa + aliasy + `source_ref` + strona + zakres regionu + flaga globalna). `resolve` po kodzie albo aliasie. UI `/networks`. Żywy ID **M-12**. Członkostwo tenanta i katalog agentów to osobne tabele z archiwum — nie ten plaster.

**Odrzucone:**

- `network_member` (tysiące agentów) — wartość jest w kolejności (Aneks 8 §5), a kolejność = M-13. Bez scrapingu i bez sui generis.
- `network_membership` jako druga tabela — przy `organization_id` na `network` wiersz katalogu **jest** członkostwem tenanta w tej sieci; numer członkowski / tier = leftover kolumn albo osobny plaster.
- Import Excel/PDF katalogu przez M-20 — HITL cenników zostaje; ingest członków = później, ręczny wpis jak 4.0/5.0.
- RapidFuzz / `dedupeio` / `network_member_link` — dopiero gdy są duplikaty agentów.
- Nadpisanie M-10 `party`, M-08 `charge`, M-11 `resolve_email`.
- Wspólny katalog SaaS bez `organization_id` — zakazane (Aneks 8 + HC).
- M-62 graf wiedzy, portale, Auth0, M-02.

## Zakres

Katalog sieci/stowarzyszenia per tenant. Lista, dodanie, `resolve`. RLS FORCE. OpenFGA `can_manage_networks` = member.

## Ustalenia

- Żywy ID: **M-12**. Token: `network` (GLOSSARY). Archiwum M-12 nie koliduje z żywym kodem.
- `code`: po normalizacji `a-z`, potem `a-z0-9_`, długość 2–32. Przykłady z Aneksu 8: `wca`, `globalia`, `jctrans`, `conqueror`, `fiata`, `pisil`, `cargo_connections`. Inny token w tym formacie wolno (izba krajowa). Puste / spoza wzorca = `InvalidNetworkCode`.
- `resolve(token)`: dokładne, po `code` albo aliasie; nieznany = `UnknownNetwork`. Nie luźna nazwa.
- Aliasy na wierszu (`text[]`), nie osobna tabela — jak `commodity_code`.
- `website` i `region_scope` opcjonalne (tekst); brak HTTP do tej strony w 9.0.
- `is_global`: boolean; katalog globalny vs krajowy (Aneks 8) — flaga, nie osobna tabela.
- `source_ref` obowiązkowy; ręczny wpis = `tenant:manual`; fixture = `network:<code>`.
- Unikat `(organization_id, code)`.
- OpenFGA: nowa relacja `can_manage_networks` = `member`. Brak tuple na wiersz.
- RLS FORCE + test izolacji dwóch organizacji.
- Job operatora: `/networks` — DataTableShell, dodanie (kod + nazwa + aliasy + strona + zakres + globalna), pole resolve.
- import-linter: `app.services.networks` niezależny BC. Extraction / quotations / charges / rate_lines / parties / commodity_codes / nbp_rates / dangerous_goods nie importują.
- Migracja `020_network_rls` (w górę i w dół).
- Kwoty nie mieszkają na katalogu. LLM nie liczy.
- `CatalogCreateForm` jest pod `code`/`name`/`aliases` — tu dokładamy `website` / `region_scope` / `is_global`; nie wpychać na siłę. `CatalogHeading` / `CatalogLoadedTable` / `TenantSessionNotice` wolno. `just dup` ≤ 3%.

## Schemat

`network`: `id`, `organization_id`, `code`, `name`, `aliases text[]`, `website`, `region_scope`, `is_global`, `source_ref`, timestamps.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z G2.14–G2.18):** jedna tabela `tender_carbon_mark` per tenant — **HITL znacznik śladu węglowego z `source_ref`**, nie silnik kg×współczynnik i nie CBAM. Wiersz = `tender_id` (FK tenanta do `tender`) + `mark_code` (`declared` | `exempt`) + `source_ref` (`tenant:manual` albo `fixture://tender-carbon-mark/…`). Operator wpisuje, czy ślad jest zadeklarowany albo zwolniony; serwis nie liczy kg, nie woła LLM, nie mutuje `tender.status` i nie czyta `charge`. Zły kod → 400 (`ślad`). Obce `source_ref` → 400 (`obce`). Unique `(organization_id, tender_id)` — jeden znacznik na przetarg. GET listy SQL. API składa odczyt nagłówka (`TenderService.get_board`). UI `/tender-carbon-marks` bez `<Money/>`, bez `sum()` i bez mnożenia w JS. `SHIPPED_CHARGE_ROUTES["184.0"]` = `/tender-carbon-marks`. OpenFGA: `can_manage_tender_carbon_marks`. Migracja `124_tender_carbon_mark`. Marża zostaje na `charge`.

**Łowca:** ISTNIEJE `charge` — jedyna prawda o marży, **nie** ślad CO₂. ISTNIEJE `dangerous_good` (żywe M-52) — UN/IMDG, **nie** CBAM. BRAK `tender_carbon_mark`. BRAK `/tender-carbon-marks`. BRAK kg na wierszu przetargu.

**Odrzucone:**

- kg / tCO₂e / współczynnik / mnożenie / float (leftover G2.15–G2.18).

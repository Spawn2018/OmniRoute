# Plaster 101.0 · S39 różnice kursowe (M-44)

**Spec źródłowa:** [docs/spec/fx-difference.md](../../spec/fx-difference.md) · [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § Kolejka S39  
**Zależy od:** 2.0 `quotation` · 6.0 `nbp_rate` · 37.0 tablica `/fx-differences` · 0.3 RLS · 0.4 OpenFGA

**Status:** Plan zaakceptowany `/noc` 2026-09-03. Ten sam żywy ID **M-44**. Nie F9.1.

## Wybrane / odrzucone / dlaczego

**Wybrane:** tabela `fx_difference` per tenant. Operator zapisuje, że ta wycena stoi przy tym kursie NBP (`quotation_id` + `nbp_rate_id` + `source_ref`). Kwoty zostają na `charge`. Kurs zostaje na `nbp_rate`. Tablica 37.0 przestaje udawać, że filtr walut to różnica kursowa. API składa: odczyt wyceny, odczyt kursu, zapis wiersza. Serwis różnicy nie importuje `quotations` / `nbp_rates` / `charges`. Wiele wierszy na jedną wycenę (kolejne tabele A). Unikat pary `(organization_id, quotation_id, nbp_rate_id)`. Wzorzec jak S38. `get_quotation` i `get_rate` już są.

**Łowca:** ISTNIEJE 37.0 `/fx-differences` + `nbpRatesForKnownCurrencies` / `fetchCharges` / `fetchQuotations`. ISTNIEJE 6.0 `nbp_rate`. ISTNIEJE 2.0 `quotation` z `uq_quotation_org_id`. BRAK tabeli `fx_difference` / `fx_gain` / `fx_loss`. PODOBNE: 100.0 `money_cost`; 98.0 `quote_invoice_settlement`. Dwa joby (kurs vs różnica) = `/nbp-rates` vs `/fx-differences`.

**Odrzucone:**

- Zostawić filtr NBP — to fundament 37.0, nie żywe M-44.
- Przeliczenie `amount × mid` albo odejmowanie kursów.
- Kolumna kwoty / `mid` / `buy` na wierszu różnicy.
- Para `charge` + kurs — `ChargeService` nie ma `get`; MixedCurrencyCharge i tak zabrania dwóch walut na `charge`.
- Księgowanie zysku/straty.
- Zapis kursu z `/fx-differences`.
- F9.1.

## Zakres

1. Migracja `059_fx_difference_rls` (po `058_money_cost_rls`): tabela `fx_difference` z RLS ENABLE+FORCE; FK tenanta do `quotation` i `nbp_rate` (oba mają już unikat org+id).
2. `GET/POST /fx-differences` — OpenFGA `can_manage_fx_differences` = member. POST: `{quotation_id, nbp_rate_id, source_ref}`. Nieznana wycena albo kurs → 404. Pusty / obcy `source_ref` → 400.
3. UI `/fx-differences`: lista wierszy tabeli + „Zapisz różnicę”. `data-fx-difference="board"` zostaje. Lista **nie** idzie z `fetchCharges` ani `nbpRatesForKnownCurrencies`. Linki do `/quotations` i `/nbp-rates` zostają. `SHIPPED_CHARGE_ROUTES["101.0"]` = `/fx-differences`. Asercje 37.0 bez `parseFloat` / mnożenia `mid` / `CatalogCreateForm` zostają; helper `nbpRatesForKnownCurrencies` zostaje w `nbp-rates-api` (test jednostkowy 37.0), nie na tablicy.
4. Test izolacji. `just api-types`. How-to `docs/operator/roznica-kursowa.md`.

## Ustalenia

- Token: `fx_difference` (tabela). How-to: `roznica-kursowa.md`.
- `source_ref`: `fixture://fx-difference/` albo `tenant:manual`. Pusty po trim = 400. Max 256.
- Serwis bez `httpx` / `requests`. ExtractionService nie importuje różnic kursowych.
- LLM nie liczy. `charge` zostaje prawdą o marży. HITL extract bez zmian.
- Formularz: nie `CatalogCreateForm` (próg `just dup` 3%).
- OPS_JOBS zostaje długości 50 (ta sama trasa).

Suma `buy_amount`, `sell_amount` i `sell_amount - buy_amount` obejmuje opłaty na korzeniu i na bezpośrednich dzieciach (`parent_shipment_id` = korzeń). Postgres liczy. Serwis `charges` nie sumuje i nie importuje `app.services.shipments`. GET czyta widok. UI `/charges` pokazuje liczby z API. `SHIPPED_CHARGE_ROUTES["614.0"]` = `/charges`. OpenFGA bez nowej relacji (`can_manage_charges`). Migracja `489_shipment_tree_margin` (po `488_charge_shipment_id`).

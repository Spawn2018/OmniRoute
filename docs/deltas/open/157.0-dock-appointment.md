# Plaster 157.0 · D3 `dock_appointment`

**Spec źródłowa:** [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § D3 · [karty-pol-fala-d.md](../../analysis/karty-pol-fala-d.md) § D3
**Zależy od:** 90.0 `shipment` · 150.0 `stop` · 4.1 `location` (odczyt kind; poza zapisem)
**Status:** Delta zaakceptowana `/noc` 2026-09-08. Nie WMS. Nie T8.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z D3):** jedna tabela `dock_appointment` per tenant — **awizacja na `stop`** w magazynie spedycyjnym. Magazyn = `location` punktu (`postal_zone` | `address`); nie druga tabela katalogu hubów (location już jest). Wiersz = `appointment_code` (snake 2–32) + FK złożone do `shipment` + `stop_id` (ten sam `shipment`) + `window_date` (DATE) + `window_start_local` / `window_end_local` (TIME, dane, nie wyliczenie) + `appointment_status` (`noted` | `advised` | `at_dock` | `released`) + `source_ref`. POST: `stop` nie z tego zlecenia → 400 (detail zawiera `trasy`). `location.kind=unlocode` na tym `stop` → 400 (detail zawiera `magazyn`) — port to T8, nie cross-dock. `window_end_local` ≤ `window_start_local` → 400 (detail zawiera `okno`). GET listy SQL. API składa odczyt `shipment`, `stop` i `location`; serwis awizacji nie importuje shipments / stops / geography / charges. UI `/dock-appointments`. `SHIPPED_CHARGE_ROUTES["157.0"]` = `/dock-appointments`. OpenFGA: `can_manage_dock_appointments`. Migracja `097_dock_appointment`.

**Łowca:** ISTNIEJE `stop` — punkt ZA/WY, nie okno doku. ISTNIEJE `location` / `terminal` — miejsce i terminal ISPS, nie awizacja LTL. ISTNIEJE `groupage_line` / `shipment_package` — linia i paczka, nie okno. GLOSSARY `terminal_appointment` = T8 (confirmed z API) — **inny** agregat, BRAK w kodzie. BRAK `dock_appointment`. BRAK `/dock-appointments`. BRAK okna TIME na `stop`.

**Odrzucone:**

- Katalog osobnej tabeli `cross_dock` / drzwi doków / overnight (leftover D3b).
- WMS e-commerce / stany / SSCC / pick (karta D3 poza).
- Yard / waga / EIR (G15).
- `terminal_appointment` confirmed z API (T8).
- Optymalizator slotów / live HTTP / kwota / marża.

# Plaster 134.0 · O1 `channel_quote.transit_days` + znaczki

**Spec źródłowa:** [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § O1 · [karty-pol-fala-o.md](../../analysis/karty-pol-fala-o.md) § O1
**Zależy od:** 13.0 `channel_quote` · 85.0 wskazanie na wycenie
**Status:** Plan zaakceptowany `/noc` 2026-09-08. Ten sam żywy ID **M-19**. Nie F9.1.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z kolejki O1):** kolumna `transit_days` (int ≥ 1, NULL na starych wierszach) na istniejącej `channel_quote`. Znaczki `is_cheapest` / `is_fastest_tt` **nie są kolumnami** — SQL w repozytorium kanału: min `amount` i min `transit_days` (tylko NOT NULL) w grupie org + POL + POD + `quote_date` + **ta sama waluta**. API zwraca flagi przy liście. UI: pole TT na `/channel-quotes` i znaczki na `/quotations` (już listuje oferty lane). Decimal zostaje na kwocie. `charge` zostaje prawdą o marży.

**Łowca:** ISTNIEJE `channel_quote` (13.0) — `amount`/`currency`/lane/`quote_date`, unikat dnia. ISTNIEJE wskazanie na wycenie (85.0). PODOBNE lista ofert na `/quotations`. BRAK `transit_days` i znaczków SQL.

**Odrzucone:**

- Kolumny `is_cheapest` / `is_fastest_tt` — karta: liczy SQL, nie magazyn.
- Przeliczenie NBP / mieszanie walut — T7.
- Min w Pythonie / JS.
- O2 ręczny POST z wyceny, O3 inquiry.

## Zakres

1. Migracja `077_channel_quote_transit`: `transit_days` nullable + CHECK ≥ 1.

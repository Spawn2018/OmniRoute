# Plaster 172.0 · G2.3 `tender_round`

**Spec źródłowa:** [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § G2.3 · [karty-pol-g2-tender.md](../../analysis/karty-pol-g2-tender.md) § Dalej `tender_round`
**Zależy od:** 169.0 `tender` (nagłówek już jest)
**Status:** Delta zaakceptowana `/noc` 2026-09-09. Nie auto-award. Nie T-SQL.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z G2.3–G2.18):** jedna tabela `tender_round` per tenant — **runda przetargu jako dane**, nie data room, nie matryca i nie kwota. Wiersz = `tender_id` (FK tenanta do `tender`) + `round_no` (INTEGER ≥ 1) + `source_ref` (`tenant:manual` albo `fixture://tender-round/…`). Zły numer → 400 (detail zawiera `runda`). Obce `source_ref` → 400 (`obce`). GET listy SQL. Serwis nie importuje tenders / tender_lots / tender_lanes / quotations / charges. API składa odczyt nagłówka (`TenderService.get_board`). UI `/tender-rounds`. `SHIPPED_CHARGE_ROUTES["172.0"]` = `/tender-rounds`. OpenFGA: `can_manage_tender_rounds`. Migracja `112_tender_round`. Marża zostaje na `charge`. Zero Money na tym ekranie.

**Łowca:** ISTNIEJE `tender` — nagłówek; **nie** dokładamy rundy jako kolumn tam. ISTNIEJE `tender_lot` / `tender_lane` — partia i korytarz; **nie** runda na tych wierszach. ISTNIEJE `tender_quote` — ważność + limit; **nie** rozszerzamy. BRAK `tender_round`. BRAK `/tender-rounds`.

**Odrzucone:**

- Data room / NDA / matryca Excel / playbook / four-eyes / win/loss / TED (leftover G2.4–G2.18).
- Auto-award.
- Kwota / marża na tym wierszu.
- Kolumny na `tender` / `tender_lot` / `tender_lane`.
- Float / T-SQL / live HTTP.

## Zakres

1. Migracja `112_tender_round`: RLS, izolacja, indeks `(organization_id, tender_id)`, unique `(organization_id, tender_id, round_no)`, CHECK `round_no >= 1`.
2. POST/GET. Zła runda / `source_ref` → 400. API składa odczyt `tender`, serwis round nie importuje tenders.
3. UI `/tender-rounds`. `just api-types`. How-to `docs/operator/runda-przetargu.md`; fold w `katalogi.md` (40 linii, bez nowej linii). Nazwy: `RoundDesk` / `roundWrite` / `persistRoundMark`.

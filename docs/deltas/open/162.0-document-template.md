## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z D9):** jedna tabela `document_template` per tenant — **szablon wydruku jako dane**, nie silnik PDF/ZPL i nie 409 wyjazdu. Wiersz = `template_kind` (`own_label` | `cmr`) + `language` (`pl` | `en`) + `layout_ref` (2–64, `[a-z0-9][a-z0-9_-]*`, wskazanie layoutu, nie T-SQL) + `output_kind` (`html_print`) + `source_ref` (`tenant:manual` albo `fixture://document-template/…`). `template_kind` spoza allowlisty → 400 (detail zawiera `rodzaj`). Zły `layout_ref` → 400 (detail zawiera `układ`). Zły `language` → 400 (detail zawiera `język`). Zły `output_kind` → 400 (detail zawiera `wyjście`). GET listy SQL. Serwis szablonu nie importuje shipments / charges / networks / quotations. UI `/document-templates`. `SHIPPED_CHARGE_ROUTES["162.0"]` = `/document-templates`. OpenFGA: `can_manage_document_templates`. Migracja `102_document_template`. Marża zostaje na `charge`.

**Łowca:** ISTNIEJE `quotation_print_template` (M-03 token `plain`/`letter` na ofercie) — **inny** job; **nie** rozszerzamy o CMR/etykietę. ISTNIEJE `print_sheet` (57.0 `@media print`) — chrome, nie katalog layoutów. ISTNIEJE `shipment_document` (`noted`/`attached`/`other`) — wskazanie bez bajtów; testy bez blob; **nie** rozszerzamy. ISTNIEJE `document_checklist_rule` / `document_dispatch_rule` — checklista/adresat na wycenie, nie layout. ISTNIEJE `shipment_package` — skan QR Omni paczki, nie `shipment_ref`. ISTNIEJE `ocean_bill` — numer HBL/MBL, nie szablon listu. ISTNIEJE `charge` — jedyna marża. BRAK `document_template`. BRAK `/document-templates`. BRAK `network_print_requirement`. BRAK `shipment.shipment_ref`.

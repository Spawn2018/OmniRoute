# Plaster 37.0 · M-44 Różnice kursowe (`fx_difference`)

**Spec źródłowa:** [docs/spec/fx-difference.md](../../spec/fx-difference.md)  
**Zależy od:** 6.0 `nbp_rate` · 1.2 `charge` waluty · 2.0 `quotation.currency`

**Status:** Delta zaakceptowana `/noc`. Wolno `/plaster`. Nie Fala 8. LLM nie liczy. Nie nowa tabela.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z Fali 6 M-44):** różnica kursowa **nie ma tabeli**. Operator widzi kursy NBP tylko dla walut, które już są na `charge` albo `quotation`. Token `fx_difference` (UI, nie tabela). Żywy ID **M-44**. 36.0 zostaje NBP+buy; 6.0 zostaje pełnym katalogiem.

**Łowca:** BRAK `fx_gain` / `fx_loss` / tabeli różnic. ISTNIEJE: `fetchNbpRates`, `fetchCharges`, `fetchQuotations`, waluty na wierszu. PODOBNE: 16.0 odczyt NBP przy wycenie; 36.0 NBP+buy.

**Odrzucone:**

- Tabela różnic / księgowanie FX — zgadywanie schematu (CURRENT).
- Przeliczenie `amount × mid` w JS — leftover Decimal w SQL.
- `charge` z dwiema walutami na buy/sell — `margin()` tego zabrania (MixedCurrencyCharge).

## Zakres

Read-only `/fx-differences`. `data-fx-difference="board"`. Brak migracji. `nbpRatesForKnownCurrencies(rates, charges, quotations)`. Linki do `/nbp-rates`, `/charges`, `/quotations`.

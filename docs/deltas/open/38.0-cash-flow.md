## Wybrane / odrzucone / dlaczego

Token `cash_flow` (UI, nie tabela). Żywy ID **M-45**. `/charges` zostaje katalogiem z marżą; `/finance` zostaje tablicą `margin()`.

**Łowca:** BRAK `cash_flow` / `ledger` / tabeli przepływów. ISTNIEJE: `fetchCharges`, `buy_amount`, `sell_amount`, `<Money/>`. PODOBNE: 33.0 samo `sell`; 36.0 samo `buy`; 15.0 `margin`.

**Odrzucone:**

- Tabela przepływów / księga / wyciąg — zgadywanie schematu (CURRENT).
- `sell − buy` w JS — to `margin()`; leftover zostaje na `/charges` i `/finance`.
- IBAN + NBP na tym ekranie — klon 35.0/36.0, `just dup`.

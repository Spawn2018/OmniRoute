## Wybrane / odrzucone / dlaczego

**Wybrane:** załącznik = **wskazanie** raportu wywiadowni na istniejącej recenzji, nie nowy limit i nie HTTP do biura. Nullable `credit_review.bureau_attachment_ref` (tekst jak `source_ref`, nie blob). PATCH dopina URI, który operator już ma. Decyzja `ok|hold|refuse` i `party.credit_limit` nietknięte. Bez nowej tabeli — jeden raport na recenzję.

**Łowca:** ISTNIEJE 14.0 `credit_review` + `source_ref` (`tenant:manual`). BRAK osobnego wskazania raportu. PODOBNE: `source_ref` (pochodzenie wpisu, nie plik); dokumenty zlecenia to S30.

**Odrzucone:**

- Auto-limit / zapis `credit_limit` / scoring osoby.
- Nowa tabela albo upload bajtów (M-38 leftover).
- Live HTTP BIK/KRD/GUS.
- Mutacja `quotation` / `noted_credit_review_id`.

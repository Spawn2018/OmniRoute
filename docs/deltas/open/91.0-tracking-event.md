# Plaster 91.0 · S29 zdarzenia trackingu (M-36)

**Spec źródłowa:** [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § Kolejka S29  
**Zależy od:** 90.0 tabela `shipment` · 29.0 tablica `/tracking` · 0.3 RLS · 0.4 OpenFGA

**Status:** Zaakceptowany `/noc` 2026-09-03. Ten sam żywy ID **M-36**. Nie F9.1.

## Wybrane / odrzucone / dlaczego

**Wybrane:** tabela `tracking_event` per tenant na **zleceniu**, nie na wycenie. Operator zapisuje zdarzenie (`departed` / `arrived` / `noted`) z czasem, który **podaje**, nie wylicza. Wiele zdarzeń na jedno `shipment`. API składa: odczyt `shipment`, zapis zdarzenia. Serwis trackingu nie importuje `shipments` / `quotations` / `geography`. Tablica 29.0 przestaje udawać, że lane wyceny to tracking. Wzorzec jak S28 (zapis z istniejącego wiersza). Mapa zostaje poza initial JS (ADR-0003).

**Łowca:** ISTNIEJE 29.0 `/tracking` + `quotationLanes` / `fetchPorts` + 90.0 `shipment`. BRAK `tracking_event` / AIS / `shipment_leg` w modelach. PODOBNE: 90.0 `shipment` z wyceny; 83.0 `carrier_inquiry` (`source_ref`, draft-check). Dwa joby (oferta vs śledzenie) = `/quotations` vs `/tracking`, jedna tabela zdarzeń.

**Odrzucone:**

- Mapa / leaflet / mapbox / Watchtower — ADR-0003, S32.
- AIS / project44 / live HTTP / współrzędne float.
- ETA liczona w Pythonie albo JS / LLM.
- `shipment_leg` (odcinki).
- Zdarzenia na `quotation` zamiast `shipment` — tablica wycen ≠ zlecenie.
- Auto-INSERT przy zapisie zlecenia.
- F9.1.

## Zakres

1. Migracja `050_tracking_event_rls` (po `049_shipment_rls`): `uq_shipment_org_id` na `shipment`; tabela `tracking_event` z RLS ENABLE+FORCE; FK tenanta do `shipment`.
2. `GET/POST /tracking-events` — OpenFGA `can_manage_tracking` = member. POST: `{shipment_id, event_kind, occurred_at, source_ref}`. Nieznane zlecenie → 404. Zły kind / pusty ref / naiwny czas → 400.
3. UI `/tracking`: lista zdarzeń + „Zapisz zdarzenie”. `data-tracking="board"` zostaje. Lista **nie** idzie z `quotationLanes`. `SHIPPED_CHARGE_ROUTES["91.0"]` = `/tracking`. Asercje 29.0 bez mapy / `eta` / leaflet zostają.
4. Test izolacji. `just api-types`. How-to `docs/operator/tracking.md`.

## Poza zakresem

S30 dokumenty · S31 wyjątki · mapa · AIS · ETA · `shipment_leg` · F9.1

## Ustalenia

- Token: `tracking_event` (tabela). UI token `tracking`. How-to: `tracking.md`.
- `event_kind` CHECK: `departed` | `arrived` | `noted`.
- `occurred_at` timestamptz — operator podaje; kod nie wylicza.
- `source_ref`: `fixture://tracking/` albo `tenant:manual`. Pusty po trim = 400. Max 256.
- Serwis bez `httpx` / `requests`. ExtractionService nie importuje trackingu.
- LLM nie liczy ETA. `charge` zostaje prawdą o marży.

## Schemat

`tracking_event` (nowa): `id`, `organization_id`, `shipment_id`, `event_kind`, `occurred_at`, `source_ref`, timestamps, `created_by`. FK tenanta do `shipment`. Indeks org+shipment+occurred_at.

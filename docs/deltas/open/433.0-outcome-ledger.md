- **Odrzucone:** rozszerzenie `suggestion_ledger` albo `prediction_ledger` — tu fakt, nie podpowiedź i nie wpisana metryka.
- **Odrzucone:** `counterfactual_run` / `benefit_ledger` / słowniki AI1.4 — kolejne wiersze Fali AI.
- **Odrzucone:** trzy BC piszące do substratu — warunek końca fali AI1, nie tego plastra.
- **Odrzucone:** FK · JSON payload · UPDATE/DELETE · kwota / marża / float · zapis LLM.

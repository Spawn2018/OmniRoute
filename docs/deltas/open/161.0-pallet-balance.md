# Plaster 161.0 · D7 `pallet_balance`

**Spec źródłowa:** [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § D7 · [karty-pol-fala-d.md](../../analysis/karty-pol-fala-d.md) § D7
**Zależy od:** 5.0 `party`
**Status:** Delta zaakceptowana `/noc` 2026-09-08. Nie giełda palet. Nie Chep HTTP.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z D7):** jedna tabela `pallet_balance` per tenant — **saldo sztuk palet na kontrahencie**, nie giełda i nie kwota. Wiersz = `pallet_kind` (`chep` | `lpr`) + FK złożone do `party` + `unit_count` (integer ≥ 0, sztuka jako dana, nie Decimal pieniędzy) + `source_ref` (`tenant:manual` albo `fixture://pallet-balance/…`). `pallet_kind` spoza allowlisty → 400 (detail zawiera `rodzaj`). `unit_count` ujemny / float / bool → 400 (detail zawiera `sztuk`). GET listy SQL. API składa odczyt `party`; serwis salda nie importuje parties / charges / shipments. UI `/pallet-balances`. `SHIPPED_CHARGE_ROUTES["161.0"]` = `/pallet-balances`. OpenFGA: `can_manage_pallet_balances`. Migracja `101_pallet_balance`. Marża zostaje na `charge`.

**Łowca:** ISTNIEJE `party` — kontrahent, nie saldo palet. ISTNIEJE `container` — ISO 6346, nie paleta. ISTNIEJE `shipment_package` — sztuka na zleceniu, nie Chep. ISTNIEJE `charge` — jedyna marża. ISTNIEJE ⌘K `command-palette` — inny byt „paleta”. BRAK `pallet_balance`. BRAK `/pallet-balances`. BRAK `pallet_kind` chep/lpr.

**Odrzucone:**

- Giełda palet / live HTTP Chep/LPR (EXP2.17 leftover D7b).
- Ruch podpisany / ujemne saldo / ledger (leftover D7c).
- Euro / EPAL jako trzeci kind (leftover D7d).
- Kwota / Decimal / depozyt na `charge`.
- Kolumny na `party` / `container` / `shipment_package`.

## Zakres

1. Migracja `101_pallet_balance`: RLS, izolacja, indeks `(organization_id, party_id)`.
2. POST/GET. Zły rodzaj / liczba sztuk / `source_ref` → 400.
3. UI `/pallet-balances`. `just api-types`. How-to `docs/operator/palety.md`.

# Plaster 169.0 · G2.0 `tender`

**Spec źródłowa:** [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § G2.0 · [karty-pol-g2-tender.md](../../analysis/karty-pol-g2-tender.md) § `tender`
**Zależy od:** P6 `tender_quote` 168.0 (oferta kupna już jest) · `party` (nabywca)
**Status:** Delta zaakceptowana `/noc` 2026-09-08. Nie auto-award. Nie T-SQL.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z G2.0):** jedna tabela `tender` per tenant — **nagłówek przetargu jako dane**, nie loty, nie rundy i nie auto-award. Wiersz = `side` (`sell` | `buy`) + `kind` (`open` | `restricted` | `sealed` | `e_auction`) + `status` (`draft` | `open` | `awarded` | `lost` | `no_bid`) + `buyer_party_id` (FK tenanta do `party`) + `deadline_at` (`DATE`) + `incoterm` (allowlista EXW…CIF jak na wycenie, nie cytat ICC) + `trade_side` (`import` | `export`) + `named_place` (wymagane przy DAP/DDP) + `source_ref` (`tenant:manual` albo `fixture://tender/…`). Zła strona → 400 (detail zawiera `strona`). Zły rodzaj → 400 (`rodzaj`). Zły status → 400 (`status`). Zły termin → 400 (`termin`). Zły Incoterm → 400 (`incoterm`). DAP/DDP bez miejsca → 400 (`miejsce`). Obce `source_ref` → 400 (`obce`). GET listy SQL. Serwis nie importuje parties / quotations / charges / tender_quotes. API składa odczyt nabywcy (`PartyService.get_party`). UI `/tenders`. `SHIPPED_CHARGE_ROUTES["169.0"]` = `/tenders`. OpenFGA: `can_manage_tenders`. Migracja `109_tender`. Marża zostaje na `charge`. Status `awarded` to dana operatora, nie four-eyes i nie auto-award. Zero Money na tym ekranie.

**Łowca:** ISTNIEJE `tender_quote` — ważność + limit orderów na wycenie; **nie** rozszerzamy o obiekt przetargu. ISTNIEJE `quotation` — oferta sprzedaży + Incoterms; **nie** dokładamy nagłówka przetargu tam. ISTNIEJE `channel_quote` — oferta kanału z kwotą; **nie** rozszerzamy. ISTNIEJE `field_carry_forward` / `incoterm_responsibility` — przeniesienie i macierz; **nie** cytat ICC i nie silnik U4. ISTNIEJE GLOSSARY `tender` = G2. BRAK tabeli `tender`. BRAK `/tenders`.

**Odrzucone:**

- `tender_lot` / `tender_lane` / `tender_round` (leftover G2.1+).
- Data room + NDA, extract RFP HITL, matryca Excel, playbook, prospecting, bid/no-bid silnik, award four-eyes, win/loss, TED, CO₂, consortium (leftover G2.1–G2.18).
- Auto-award (zakaz G2).
- Kwota / marża na tym wierszu (zostaje `charge` / `tender_quote` / `quotation`).
- Matching kalendarza U4 (leftover: `deadline_at` to data, nie `is_working_day`).
- Kolumny na `tender_quote` / `quotation`.
- Float / T-SQL / live HTTP / scrape TED.

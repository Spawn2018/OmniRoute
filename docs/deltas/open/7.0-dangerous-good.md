**Zależy od:** 0.3 RLS · 0.4 OpenFGA · 0.6 DataTableShell · wzorzec katalogu 5.2 `commodity_code`

**Status:** Delta zaakceptowana `/noc` 2026-09-01. Wolno `/plaster`. Nie Fala 2.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z kolejki Q6):** jeden katalog per tenant — tabela `dangerous_good` (numer UN jako token + klasa IMDG + nazwa + aliasy + `source_ref`). `resolve` po numerze UN albo aliasie. UI `/dangerous-goods`. Żywy ID **M-52** (token `dangerous_good` z GLOSSARY). Nie M-08 — żywe M-08 = `charge`.

**Odrzucone:**

- Podpięcie do `quotation` / `commodity_code` / `rate_line` w tym plastrze — kolejka Q6 to katalog, nie drugi wymiar wyceny.
- Nadpisanie żywego M-08 `charge`.
- Osobne katalogi ADN / ADR / RID — pierwsza tabela to IMDG (klasa 1–9 z podziałem 2.1 / 4.1 / …). Inne regulaminy czytają ten sam token UN później albo dostaną własny plaster.
- Grupa zgodności klasy 1 (`1.1A`), packing group, marine pollutant, limited quantity, tunnel code — atrybuty, nie pierwszy katalog.
- Seed całej listy UN (tysiące wierszy) i live HTTP do IMO — jak 4.0/5.0: fixture + ręczny wpis.
- Druga tabela aliasów, pgvector, scoring ryzyka.

## Zakres

Katalog towaru niebezpiecznego per tenant. Lista, dodanie, `resolve`. RLS FORCE. OpenFGA `can_manage_dangerous_goods` = member.

## Ustalenia

- Żywy ID: **M-52**. Token: `dangerous_good`. Archiwum M-08 „towary niebezpieczne” nie używa numeru M-08 w kodzie (żywe M-08 = `charge`). Fala 8 „Compliance” (M-53–M-56) zostaje na później; ten katalog nie jest drugim silnikiem `charge`.
- `un_number`: 4 cyfry po normalizacji (prefiks `UN` zbędny). Puste / nie-cyfry = `InvalidDangerousGood`.
- `imdg_class`: allowlista klas IMDG (1, 1.1–1.6, 2.1–2.3, 3, 4.1–4.3, 5.1–5.2, 6.1–6.2, 7, 8, 9). Inne = `InvalidImdgClass`.
- `resolve(token)`: dokładne, po `un_number` albo aliasie; nieznany = `UnknownDangerousGood`. Nie luźna nazwa.
- Aliasy na wierszu (`text[]`), nie osobna tabela — jak `commodity_code`.
- `source_ref` obowiązkowy; ręczny wpis = `tenant:manual`; fixture = `imdg:<un_number>`.
- Unikat `(organization_id, un_number)`.
- OpenFGA: nowa relacja `can_manage_dangerous_goods` = `member`. Brak tuple na wiersz.
- RLS FORCE + test izolacji dwóch organizacji.
- Job operatora: `/dangerous-goods` — DataTableShell, dodanie (UN + klasa + nazwa + aliasy), pole resolve.
- import-linter: `app.services.dangerous_goods` niezależny BC. Extraction / quotations / charges / rate_lines / commodity_codes / nbp_rates nie importują.
- Migracja `019_dangerous_good_rls` (w górę i w dół).
- Kwoty nie mieszkają na katalogu. LLM nie liczy i nie nadaje klasy.
- `CatalogCreateForm` jest pod `code`/`name`/`aliases` — tu jest `un_number` + `imdg_class`; nie wpychać na siłę. `CatalogHeading` / `CatalogLoadedTable` / `TenantSessionNotice` wolno. `just dup` ≤ 3%.

## Schemat

`dangerous_good`: `id`, `organization_id`, `un_number` (4 cyfry), `imdg_class`, `name`, `aliases text[]`, `source_ref`, timestamps.

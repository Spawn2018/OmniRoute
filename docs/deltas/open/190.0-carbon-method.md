Operator wpisuje, jaką metodykę tenant stosuje; serwis nie liczy kg, nie woła sieci, nie woła LLM i nie czyta `charge` / `tender` / `shipment`. Zły kod → 400 (`metoda`). Zła wersja → 400 (`wersja`). UI `/carbon-methods` bez `<Money/>` i bez `sum()` w JS. `SHIPPED_CHARGE_ROUTES["190.0"]` = `/carbon-methods`. OpenFGA: `can_manage_carbon_methods`. Migracja `130_carbon_method`. Marża zostaje na `charge`. `tender_carbon_mark` zostaje znacznikiem na przetargu.

**Łowca:** ISTNIEJE `tender_carbon_mark` — HITL declared/exempt na `tender`, **nie** katalog metodyki tenanta. ISTNIEJE `dangerous_good` — UN/IMDG, **nie** GLEC. ISTNIEJE `monitoring_scheme` — kod schematu SENT, **nie** CO₂. BRAK tabeli `carbon_method`. BRAK `/carbon-methods`. BRAK kg na wierszu. BRAK silnika GLEC.

# Plaster 92.0 · S30 dokumenty na zleceniu (M-38)

**Spec źródłowa:** [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § Kolejka S30  
**Zależy od:** 90.0 tabela `shipment` · 31.0 tablica `/shipment-documents` · 0.3 RLS · 0.4 OpenFGA

**Status:** Zamknięty `/noc` 2026-09-03. Ten sam żywy ID **M-38**. Nie F9.1.

## Wybrane / odrzucone / dlaczego

**Wybrane:** tabela `shipment_document` per tenant na **zleceniu**, nie na wycenie. Operator zapisuje wskazanie dokumentu (`noted` / `attached` / `other`) z `source_ref`. Wiele dokumentów na jedno `shipment`. API składa: odczyt `shipment`, zapis dokumentu. Serwis dokumentów nie importuje `shipments` / `quotations` / `extraction`. Tablica 31.0 przestaje udawać, że `source_ref` wyceny to dokument zlecenia. Wzorzec jak S29 (zapis na istniejącym `shipment`). Skan i HITL zostają w M-20.

**Łowca:** ISTNIEJE 31.0 `/shipment-documents` + `quotationAcceptancePending` / `fetchQuotations` / `<Money/>` + 90.0 `shipment`. BRAK tabeli `shipment_document` / HBL / B/L w modelach. PODOBNE: 91.0 `tracking_event` na zleceniu; 90.0 `shipment` z wyceny. Dwa joby (oferta vs dokument) = `/quotations` vs `/shipment-documents`, jedna tabela dokumentów.

**Odrzucone:**

- Bajty pliku / upload / PDF / `@media print` / U-print — leftover; skan = M-20.
- HBL / B/L / waybill jako kolumny albo kind.
- Dokument na `quotation` zamiast `shipment` — tablica wycen ≠ zlecenie.
- Auto-INSERT przy zapisie zlecenia.
- Kwota / marża na wierszu dokumentu.
- Treść pisana przez LLM.
- F9.1.

## Zakres

1. Migracja `051_shipment_document_rls` (po `050_tracking_event_rls`): tabela `shipment_document` z RLS ENABLE+FORCE; FK tenanta do `shipment` (nośnik `uq_shipment_org_id` już z 050).
2. `GET/POST /shipment-documents` — OpenFGA `can_manage_shipment_documents` = member. POST: `{shipment_id, document_kind, source_ref}`. Nieznane zlecenie → 404. Zły kind / pusty ref → 400.
3. UI `/shipment-documents`: lista wierszy tabeli + „Zapisz dokument”. `data-shipment-document="board"` zostaje. Lista **nie** idzie z `quotationAcceptancePending`. `SHIPPED_CHARGE_ROUTES["92.0"]` = `/shipment-documents`. Asercje 31.0 bez `pdf` / `print` / `hbl` / `CatalogCreateForm` zostają.
4. Test izolacji. `just api-types`. How-to `docs/operator/dokument-zlecenia.md`.

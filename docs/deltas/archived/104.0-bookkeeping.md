**Status:** Zamknięty `/noc` 2026-09-03. Ten sam żywy ID **M-47**. Nie F9.1.

## Wybrane / odrzucone / dlaczego

**Wybrane:** tabela `bookkeeping` per tenant. Operator zapisuje, że ta opłata idzie na tę fakturę (`charge_id` + `sales_invoice_id` + `source_ref`). Kwoty zostają na `charge`. Tablica 40.0 przestaje udawać, że join kodu z nazwą to dekret. API składa: odczyt opłaty, odczyt faktury, zapis wiersza. Serwis księgowości nie importuje `charges` / `sales_invoices`. Wiele wierszy na jedną fakturę (kolejne opłaty). Unikat pary `(organization_id, charge_id, sales_invoice_id)`. Wzorzec jak S41. `get_invoice` już jest. `ChargeService.get_charge` (odczyt po id) — repozytorium już ma `get`. Migracja dokłada `uq_charge_org_id` (FK tenanta).

**Łowca:** ISTNIEJE 40.0 `/bookkeeping` + `bookkeepingLines` / `fetchCharges` / `fetchChargeCodes` / `<Money/>`. ISTNIEJE 1.2 `charge` (brak unikat org+id). ISTNIEJE 96.0 `sales_invoice` z `uq_sales_invoice_org_id` i `get_invoice`. BRAK tabeli `bookkeeping` / dekretów / JPK. PODOBNE: 98.0 `quote_invoice_settlement` (wycena+faktura, nie opłata). Dwa joby (opłata vs dekret) = `/charges` vs `/bookkeeping`. `ChargeService` nie miał `get` — S39/S40 omijały M-08; tu opłata jest obiektem tablicy 40.0.

**Odrzucone:**

- Zostawić join `charge`+nazwa kodu — to fundament 40.0, nie żywe M-47.
- `sell − buy` w JS albo w Pythonie — to `margin()`.
- Kolumna kwoty / konto / JPK na wierszu.
- HTTP do ERP / plik CSV.
- Para wycena+faktura — już jest `quote_invoice_settlement`.
- F9.1.

## Zakres

1. Migracja `062_bookkeeping_rls` (po `061_cost_to_serve_rls`): `uq_charge_org_id` jeśli brak; tabela `bookkeeping` z RLS ENABLE+FORCE; FK tenanta do `charge` i `sales_invoice`.
2. `ChargeService.get_charge` — odczyt, `ResourceNotFound` gdy brak (404 w API). Bez zapisu opłaty z tego plastera.

4. UI `/bookkeeping`: lista wierszy tabeli + „Zapisz dekret”. `data-bookkeeping="board"` zostaje. Lista **nie** idzie z `fetchCharges` / `bookkeepingLines` / `fetchChargeCodes` na tablicy. Linki do `/charges` i `/invoices` zostają. `SHIPPED_CHARGE_ROUTES["104.0"]` = `/bookkeeping`. Asercje 40.0 bez `parseFloat` / odejmowania / `CatalogCreateForm` zostają; helper `bookkeepingLines` zostaje w `charges-api` (test jednostkowy 40.0), nie na tablicy.
5. Test izolacji. `just api-types`. How-to `docs/operator/ksiegowosc.md`.

- **Wybrane:** operator poprawia propozycję **zanim** wciśnie accept. Accept 1.3 zostaje. Serwis ekstrakcji nadal **nie** zapisuje `rate_line` (HC-04).
- **Wybrane:** 409 gdy status ≠ `pending`. 422 gdy `draft_kind` ≠ `rate_line` albo kandydat psuje schemat. `extra=forbid`.
- **Wybrane:** UI `/extractions` — edycja kandydatów na wybranym szkicu, potem istniejący accept/reject.
- **Odrzucone:** wersjonowanie / `bbox` / pewność (`REJECTED` — AI3.1).
- **Odrzucone:** PATCH `input_text` / `source_ref` / `status` / `draft_kind` (`REJECTED` — źródło i decyzja zostają osobno).
- **Odrzucone:** PATCH quote/rfp (`REJECTED` na 447.0).
- **Odrzucone:** ponowne wołanie LLM · float · zapis `charge` · auto-accept.

**Łowca:** ISTNIEJE POST create + accept/reject. PODOBNE `payload.candidates` (schemat `ExtractedChargeCandidate`). BRAK PATCH. `just dup` bez wyodrębnienia.

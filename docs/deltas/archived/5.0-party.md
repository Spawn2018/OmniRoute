# Plaster 5.0 · M-10 Kontrahenci (`party` i katalog zależny)

**Spec źródłowa:** [docs/spec/parties.md](../../spec/parties.md)  
**Zależy od:** 0.3 RLS · 0.4 OpenFGA · 0.6 DataTableShell · 1.0 `charge_code` (FK wyjątku) · 4.2 `terminal` (`operator_party_id`)

**Status:** Zamknięty 2026-09-01. Plan zaakceptowany, kod w repo, `just gate` zielony lokalnie.

## Zakres

Katalog kontrahenta per tenant: `party` plus `party_contact`, `party_bank_account`, `party_email_domain`, `party_charge_override`, `carrier_profile`. Lookup GUS/VIES i białej listy zwraca szkic — zapis dopiero po potwierdzeniu operatora. UI `/parties` (DataTableShell). Leftover 4.2: nullable `terminal.operator_party_id`.

## Poza zakresem

Q3 (`quotation` + port + `party_id`) · Q4–Q6 · M-11 match domeny z maila · M-12 sieci · M-13 karta wyników · M-14 automatyczny scoring osoby/JDG · M-19 żywe adaptery armatorskie · portal (`portal_access` / `portal_user_id`) · M-02 outbox · Auth0 · Exit Wave FE · leftovery UI ADR-0003 · OpenFGA per `party` („handlowiec widzi swoich”) · `quotation` / `charge.margin()` czytające `party_charge_override` · `kind='terminal'` na `location`.

## Ustalenia

- Żywy ID modułu: **M-10**. Brak kolizji z żywym M-07 `rate_line` / M-08 `charge`. Archiwalne numery 1.5/1.6 nie używać. Plaster **5.0** = cały katalog M-10 w jednym przebiegu (decyzja operatora 2026-09-01).
- Archiwalny SQL bez `organization_id` / `source_ref` — oba obowiązkowe. Adres kolumnami (`address_line`, `city`, `postal_code`), nie `jsonb`.
- OpenFGA: nowa relacja `can_manage_parties` = `member`. Geografia bez zmiany `can_manage_geography`. Brak tuple na pojedynczy `party`.
- RLS FORCE na każdej nowej tabeli + test izolacji dwóch organizacji. Runtime `omniroute_app` NOBYPASSRLS. Dzieci: FK złożone `(organization_id, party_id)` → `party(organization_id, id)` — nośnik `UNIQUE (organization_id, id)`.
- Job operatora: `/parties` — lista, dodanie, `resolve` po `tax_id`, lookup (szkic), panele kontaktów / rachunków / domen / profilu armatora / wyjątków stawek. Na `/terminals`: picker `operator_party_id` (API `/parties`); `operator_name` zostaje. Geografia nie importuje `app.services.parties`.
- `resolve(tax_id)`: dokładne, bez wielkości liter; nieznany = `UnknownParty`. Nie luźna nazwa. Unikat częściowy `(organization_id, country_code, tax_id)` gdy `tax_id` nie NULL. PL + `tax_id`: 10 cyfr i suma kontrolna NIP; inny kraj = niepusty token.
- Lookup GUS/VIES/biała lista: idempotencja + timeout; **nie INSERT**. CI = fixture, zero sieci. Sandbox REGON bez klucza w repo. Dane zewnętrzne niezaufane; człowiek akceptuje przed zapisem.
- `roles text[]`: wyłącznie `customer`, `vendor`, `agent`, `carrier`, `shipper`, `consignee`, `notify`.
- `credit_limit` + `credit_currency`: Numeric, ręcznie, para albo oba NULL. Nie scoring (M-14). LLM nie liczy.
- `party_charge_override`: Decimal + waluta + `source_ref`. FK bazowe do `charge_code(organization_id, code)` bez importu serwisu `charge_codes`. **Nie** druga marża — silnik wyceny w 5.0 tej tabeli nie czyta.
- `carrier_profile`: 1:1 z `party`. Kolumny (`scac_code`, `is_nvocc`, `rate_source_email`, `api_adapter`, `dcsa_tnt_version`). Zero HTTP do armatorów.
- `party_email_domain`: domena lowercase; unikat `(organization_id, domain)`. Katalog, nie matcher M-11.
- `party_contact`: bez kolumn portalu.
- `source_ref` ręcznego wpisu = `tenant:manual`. Lookup zaakceptowany = `tenant:lookup:<źródło>`.
- Migracja `015_party_rls` (w górę i w dół), w tym ALTER `terminal.operator_party_id`.
- import-linter: dodać `app.services.parties` do kontraktu niezależności. Extraction nadal nie zna stawek.

## Schemat

`party`: `id`, `organization_id`, `legal_name`, `short_name` (nullable), `tax_id` (nullable), `vat_eu` (nullable), `regon` (nullable), `krs` (nullable), `country_code` CHAR(2), `address_line` / `city` / `postal_code` (nullable), `roles text[]`, `payment_terms_days` (nullable int), `credit_limit` Numeric(14,4) nullable, `credit_currency` CHAR(3) nullable, `default_currency` CHAR(3) nullable, `language` (nullable), `gus_synced_at` / `vies_checked_at` (nullable timestamptz), `is_active` (default true), `source_ref`, timestamps.

`party_contact`: `organization_id`, `party_id`, `name`, `email` (nullable), `phone` (nullable), `position` (nullable), `is_primary`.

`party_bank_account`: `organization_id`, `party_id`, `iban`, `currency` CHAR(3), `bank_name` (nullable), `whitelist_status` (`pending` | `listed` | `not_listed` | `unavailable`), `whitelist_checked_at` (nullable).

`party_email_domain`: `organization_id`, `party_id`, `domain`, `source_ref`.

`party_charge_override`: `organization_id`, `party_id`, `charge_code`, `lane_pattern` (nullable text), `amount` Numeric(14,4), `currency` CHAR(3), `basis` (nullable), `valid_from` / `valid_to` (nullable date), `source_ref`.

`carrier_profile`: `organization_id`, `party_id` UNIQUE, `scac_code` (nullable), `is_nvocc` bool, `rate_source_email` (nullable), `api_adapter` (`none` | `maersk` | `hapag` | `cma` | `msc`), `dcsa_tnt_version` (nullable).

`terminal` (ALTER): `operator_party_id` UUID nullable; FK `(organization_id, operator_party_id)` → `party(organization_id, id)` ON DELETE RESTRICT.

## Rozstrzygnięcia z realizacji

- Lookup w CI to `PARTY_LOOKUP_BACKEND=fixture` — `httpx.Timeout` jest w źródle, zero HTTP.
- `resolve` nie waliduje NIP: token po strip/uppercase; luźna nazwa pada jako `UnknownParty`.
- CHECKi `ck_party_roles` / `ck_party_credit_pair` i indeks częściowy tax_id siedzą na modelu ORM, więc `create_all` w teście je odtwarza.

# Plaster 70.0 · S7 HS/CN na RFQ i wycenie (M-09)

**Spec źródłowa:** [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § Kolejka S7  
**Zależy od:** 5.2 `commodity_code` · 67.0 `customer_rfq` · 68.0 `quotation.customer_rfq_id` · 0.4 OpenFGA

**Status:** Zamknięty `/noc` 2026-09-03. Katalog jest. LLM nie liczy. Nie F9.1.

## Wybrane / odrzucone / dlaczego

**Wybrane:** ten sam katalog `commodity_code` (`resolve` / `normalize_commodity_code`). Nullable `commodity_code_id` na `customer_rfq` i na `quotation`. FK złożone tenanta. API składa: ładuje kod przez `CommodityCodeService` (`get` po id albo `resolve` tokenu), potem zapisuje samo UUID. Serwis katalogu nie zapisuje RFQ ani wyceny. Serwis RFQ i serwis wyceny nie importują `commodity_codes`. Kwota wyceny nadal z `QUOTE_FROM_CURRENT_SQL` — kod HS nie filtruje stawki. OpenFGA bez nowej relacji: `can_manage_customer_rfqs` / `can_manage_quotations`. Ekrany: `/mail` (podpięcie kodu do RFQ) i `/quotations` (picker + dziedziczenie z RFQ).

**Łowca:** ISTNIEJE: `CommodityCodeService.resolve`, lista/create, UI `/commodity-codes`, `customer_rfq.party_id`, `quotation.customer_rfq_id`, API składa RFQ przy `POST /quotations`. PODOBNE: `require_rfq_party` (skład API, nie serwis wyceny); `get_rfq`. BRAK: `commodity_code_id` na RFQ/wycenie; `get` po id w katalogu; PATCH RFQ; picker HS poza katalogiem.

**Odrzucone:**

- Nowy katalog albo luźny string HS na RFQ/wycenie (5.2 już jest tokenem cyfr).
- Zapis `commodity_code` z serwisu RFQ / wyceny / ExtractionService.
- Filtrowanie `rate_line` po HS (S7 = etykieta ładunku, nie nowy silnik).
- UN / IMDG / `dangerous_good_id` (PLAN: opcjonalnie; M-52 to inny BC — leftover, nie LLM).
- Wymóg HS przy każdej wycenie — nullable zostaje.
- Auto-HS z treści maila / LLM.
- F9.1 · Auth0 · portale · M-02.
- Nowa relacja OpenFGA.

## Zakres

1. Migracja `031_commodity_on_rfq`: `uq_commodity_code_org_id` na `(organization_id, id)`; `commodity_code_id` na `customer_rfq` i `quotation`; FK złożone; indeksy `(organization_id, commodity_code_id)`. Bez nowej tabeli, bez nowego RLS.
2. `get` w serwisie katalogu (odczyt). `PATCH /customer-rfqs/{id}` z `commodity_code_id`. `POST /quotations` (i wsad) z opcjonalnym `commodity_code_id`; puste + RFQ z kodem = dziedziczenie. `GET` filtr po kodzie nie jest wymagany.
3. Test: kod tenanta B nie siada na RFQ/wycenie A; nieznany kod = błąd; kwota = `rate_line`, nie body; ścieżka bez HS bez zmian; `QUOTE_FROM_CURRENT_SQL` nie czyta `commodity_code` ze stawki.
4. `/mail`: podpięcie HS do istniejącego RFQ. `/quotations`: picker kodu, kolumna, dziedziczenie z RFQ. `<Money/>` bez zmian.

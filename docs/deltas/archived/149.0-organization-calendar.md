Zero pętli w Pythonie. Grace V5 (3 dni robocze bez trip) = leftover — tu tylko kalendarz.

UI `/organization-settings`. `SHIPPED_CHARGE_ROUTES["149.0"]` = `/organization-settings`. OpenFGA: `can_manage_organization_settings`. Migracja `089_organization_calendar`.

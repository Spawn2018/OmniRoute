**Status:** Zamknięty `/noc` 2026-09-09. Nie auto-award. Nie T-SQL.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z G2.2–G2.18):** jedna tabela `tender_lane` per tenant — **korytarz partii jako dane**, nie runda, nie data room i nie kwota. Wiersz = `tender_lot_id` (FK tenanta do `tender_lot`) + `origin_unlocode` + `destination_unlocode` (token UN/LOCODE 5 znaków, nie luźna miejscowość; format przez istniejące `normalize_unlocode`, bez resolve katalogu `port`) + `source_ref` (`tenant:manual` albo `fixture://tender-lane/…`). Pusty / zły / ten sam origin=dest → 400 (detail zawiera `korytarz`). Obce `source_ref` → 400 (`obce`). GET listy SQL. Serwis nie importuje tender_lots / tenders / geography / quotations / charges. API składa odczyt partii (`TenderLotService.get_lot`). UI `/tender-lanes`. `SHIPPED_CHARGE_ROUTES["171.0"]` = `/tender-lanes`. OpenFGA: `can_manage_tender_lanes`. Migracja `111_tender_lane`. Marża zostaje na `charge`. Zero Money na tym ekranie.

**Łowca:** ISTNIEJE `tender_lot` — kod partii; **nie** dokładamy korytarza jako kolumn tam. ISTNIEJE `tender` — nagłówek; **nie** lane na nagłówku. ISTNIEJE `tender_quote` — ważność + limit; **nie** rozszerzamy. ISTNIEJE `party_lane_scorecard` — karta POL/POD kontrahenta; **nie** korytarz przetargu. ISTNIEJE `normalize_unlocode` — format tokenu; **nie** drugi parser. BRAK `tender_lane`. BRAK `/tender-lanes`.

**Odrzucone:**

- `tender_round` / data room / matryca Excel (`tender_matrix_cell` z kwotą z P) / playbook / four-eyes / win/loss / TED (leftover G2.3–G2.18).

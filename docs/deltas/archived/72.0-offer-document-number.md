## Wybrane / odrzucone / dlaczego

**Wybrane:** ten sam panel `data-offer-document` na `/quotations` i ten sam `@media print` z 57.0. Nullable `quotation.document_number`. Operator klika „Nadaj numer”: API składa — odczyt prefiksu z `OrganizationSettingService` (`get` po kluczu), serwis wyceny dostaje sam string prefiksu i zapisuje numer. Kolejny numer liczy **Postgres** (`MAX` ogona cyfr + 1), nie pętla w Pythonie i nie klucz w ustawieniach. Format: znormalizowany prefiks + cztery cyfry (`OR-Q.0001`). Unikat `(organization_id, document_number)`. Drugie nadanie na tym samym wierszu zwraca ten sam numer (niemutowalny). Token `quotation_print_template` idzie na panel jako `data-print-template` — bez nowego silnika CSS. „Drukuj” woła `window.print()`; chrome chowa 57.0. OpenFGA bez nowej relacji: `can_manage_quotations`. Kwota zostaje ze stawki.

**Łowca:** ISTNIEJE: `OfferDocumentPanel`, `data-offer-document="preview"`, `@media print` w `index.css`, `print-sheet.test.ts`, `quotation` + `QUOTE_FROM_CURRENT_SQL`, klucze `quotation_number_prefix` / `quotation_print_template`, `find_by_key` w repo ustawień, `can_manage_quotations`. PODOBNE: skład API jak 68.0/70.0 (serwis A nie importuje serwisu B); odczyt `default_currency` na `/rollout`. BRAK: kolumny `document_number`; `get` w serwisie ustawień; endpoint nadania numeru; prefiks/szablon na panelu; przycisk Drukuj.

## Zakres

1. Migracja `032_quotation_document_number`: `document_number` VARCHAR(32) nullable; unikat częściowy `(organization_id, document_number)` gdzie numer nie jest NULL. Bez nowej tabeli, bez nowego RLS.
2. `get` odczytu klucza w serwisie ustawień. `POST /quotations/{id}/document-number`. Serwis wyceny: `issue_document_number(prefix)` — SQL nadaje kolejny, brak prefiksu = błąd domenowy, drugi raz = ten sam numer.
3. Test: tenant B nie nadaje numeru na wycenie A; ten sam tekst numeru legalny u B; brak prefiksu pada; kwota bez zmian; 403 bez tuple; serwisy bez krzyżowych importów.
4. `/quotations` panel: numer, `data-print-template`, „Nadaj numer”, „Drukuj”. Nie licz w JS.

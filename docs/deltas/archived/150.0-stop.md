## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z T1):** jedna tabela punktu na zleceniu per tenant. Wiersz = `shipment_id` + `stop_kind` (`loading` | `unloading` | `customs` | `ferry` | `terminal` | `depot` | `other`) + `sequence_no` + `location_id` + `time_zone` (IANA `Continent/City`) + `status` (`pending` | `at_stop` | `completed` | `failed`) + `source_ref`. GET SQL po `shipment_id` (bieżące). Zmiana kind/statusu/miejsca/strefy = nowy wiersz + `superseded_by`. Złożone FK `(organization_id, shipment_id)` jak `cargo_claim` oraz `(organization_id, location_id)` jak `location`→`port`. `location_id` wymagane — nieznane miejsce = 400, nie luźny adres. Unikat `sequence_no` w ramach zlecenia tylko wśród bieżących (bez partial unique — override jak `rate_line`).

UI `/shipments`. `SHIPPED_CHARGE_ROUTES["150.0"]` = `/shipments`. OpenFGA: `can_manage_shipments`. Migracja `090_stop`.

**Łowca:** ISTNIEJE `shipment_leg` (odcinek road/rail/lcl) — **inny** agregat, nie punkt ZA/WY. ISTNIEJE `location` / `port`. ISTNIEJE GLOSSARY `eta_physical` / `eta_legal` (V2). BRAK tabeli `stop`. BRAK `stop_group`. BRAK timezone na zleceniu.

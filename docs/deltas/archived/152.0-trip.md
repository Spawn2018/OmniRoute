# Plaster 152.0 · T2b `trip`

**Spec źródłowa:** [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § T2 · [karty-pol-fala-t.md](../../analysis/karty-pol-fala-t.md) § T2 · S50 = T2
**Zależy od:** 151.0 `resource`
**Status:** Zamknięty `/noc` 2026-09-08. Nie Decimal km. Nie HW.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z leftover T2):** jedna tabela przejazdu per tenant. Wiersz = `trip_no` + `status` (`draft` | `planned` | `in_transit` | `completed` | `cancelled`) + opcjonalne `vehicle_id` / `trailer_id` / `driver_id` (FK do `resource`, złożone `(organization_id, …)`) + `source_ref`. Override tego samego `trip_no` = nowy wiersz + `superseded_by`. GET listy SQL (bieżące). UI `/shipments`. `SHIPPED_CHARGE_ROUTES["152.0"]` = `/shipments`. OpenFGA: `can_manage_shipments`. Migracja `092_trip`. Unique `(organization_id, id)` na `resource` (`uq_resource_org_id`) — złożone FK.

**Łowca:** ISTNIEJE `resource` (151.0). ISTNIEJE `stop` / `shipment_leg`. BRAK `trip`. BRAK `stop_group`. BRAK `/fleet`.

**Odrzucone:**

- `driver2_id` / multi-manning (leftover T2c).
- `subcontractor_party_id` (M-10).
- `planned_distance_km` / `actual_distance_km` / Decimal / snapshot kosztu (Fala P).
- `document_expiries` przy przypisaniu.
- podpinanie `stop` do tripa (`stop_group`).
- własne HW / mapa / `/fleet`.

## Zakres

1. Migracja `092_trip`: RLS, izolacja, indeks `(organization_id, status)`, złożone FK do `resource`.
2. POST/GET. Obcy status / kind zasobu nie pasuje do slotu (`driver` na `vehicle_id`) / brak source_ref → 400.
3. UI `/shipments`. `just api-types`. How-to w `katalogi.md` wtopione (40 linii).

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z leftover T4b SQL `charge` + leftover rollup drzewa shipment + leftover lookup/KSeF TE + leftover T5 + leftover T7b + leftover N3 + S53 + PIN):** leftover rollup główne+podzlecenia parked — na `charge` nie ma `shipment_id`. leftover lookup/KSeF parked. leftover T5 parked. leftover T7b parked. leftover N3 parked. S53 parked. PIN parked. Żywy plaster: **GET listy `charge`** zwraca `margin_amount` / `margin_currency` z Postgres (`sell_amount - buy_amount`, ta sama waluta już w CHECK), nie z `margin()` w `ChargeResponse.from_row`. POST nadal woła `margin()` w serwisie (odrzut mieszanej waluty zanim INSERT). Brak nowej tabeli i brak kolumny magazynu marży. `SHIPPED_CHARGE_ROUTES["262.0"]` = `/charges`. OpenFGA bez nowej relacji. UI `/charges` bez odejmowania w JS.

**Łowca:** ISTNIEJE `margin()` w domenie i w `ChargeResponse.from_row` (Python na GET). ISTNIEJE CHECK `buy_currency = sell_currency`. ISTNIEJE kolumna `margin_amount` w JSON, nie w tabeli. BRAK `shipment_id` na `charge`. BRAK `select(sell - buy)` w repozytorium.

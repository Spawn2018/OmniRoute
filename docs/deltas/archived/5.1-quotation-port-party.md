# Plaster 5.1 · M-21 wycena z portem i kontrahentem

**Spec źródłowa:** [docs/spec/quotation.md](../../spec/quotation.md)  
**Zależy od:** 2.0 `quotation` · 4.0 `port` · 5.0 `party` · 0.3 RLS · 0.4 OpenFGA · 0.6 DataTableShell

**Status:** Zamknięty 2026-09-01. Kod na origin. Nie Q4.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z kolejki Q3):** trzy FK na istniejącym `quotation` — `origin_port_id` (POL), `destination_port_id` (POD), `party_id`. Lista i filtry w SQL. Kwota nadal wyłącznie INSERT…SELECT z bieżącego `rate_line` (`superseded_by IS NULL`). Jeden ekran `/quotations`.

**Odrzucone:**

- Kolumny portu / kontrahenta na `rate_line` — kolejka każe SQL na **istniejących** stawkach; to byłby drugi wymiar silnika stawek (zakazany przy żywym M-07).
- `party_charge_override` w doborze kwoty — katalog uzgodnień, nie silnik wyceny; 5.0 i CURRENT to zamykają.
- Dwa plastry (najpierw port, potem `party`) — job operatora to jeden formularz wyceny; rozbicie zostawia dziurawy ekran.
- `terminal_id` na wycenie, marża, k6, tuple OpenFGA per wiersz.

## Zakres

Snapshot POL/POD + kontrahent na `quotation`. Filtry listy. Kwota ze stawki, nigdy z requestu / LLM / Pythona.

## Poza zakresem

Q4–Q6 · `party_charge_override` → wycena · kolumny na `rate_line` · `charge.margin()` · k6 · HITL · outbox · ExtractionService→rates/parties · Auth0 · M-02 · portale · Exit Wave FE · leftovery UI ADR-0003 · `kind='terminal'` na `location`.

## Ustalenia

- Żywy ID: **M-21**. Brak kolizji z żywym M-07 `rate_line` / M-08 `charge`.
- Port i kontrahent **nie dobierają stawki**. `QUOTE_FROM_CURRENT_SQL` nadal filtruje tylko `charge_code` + `superseded_by IS NULL`. Trzy UUID wchodzą jako bind z requestu i lądują na wierszu.
- FK złożone, tenant-safe, `ON DELETE RESTRICT`.
- CHECK `ck_quotation_lane_party_complete`: albo wszystkie trzy NULL (wiersze 2.0), albo wszystkie trzy NOT NULL (nowa wycena).
- POST wymaga trójki. Obcy tenant = FK. Serwis wyceny nie importuje `parties` / `geography`.
- Lista: `GET /quotations` z opcjonalnymi filtrami w SQL. OpenFGA bez zmian: `can_manage_quotations`.
- Job operatora: `/quotations` — DataTableShell, picker kontrahenta i dwóch portów, filtry listy.
- Migracja `016_quotation_port_party` (w górę i w dół).

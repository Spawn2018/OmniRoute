## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z T3):** jedna tabela kontenera per tenant. Wiersz = `container_no` (ISO 6346 + cyfra kontrolna w domenie) + `iso_size_type` (4 znaki ISO, nie słownik TEU) + opcjonalny `shipment_id` (FK złożone `(organization_id, shipment_id)`) + `source_ref`. Override tego samego `container_no` = nowy wiersz + `superseded_by`. GET listy SQL (bieżące), opcjonalny filtr typu. UI `/shipments`. `SHIPPED_CHARGE_ROUTES["153.0"]` = `/shipments`. OpenFGA: `can_manage_shipments`. Migracja `093_container`.

**Łowca:** ISTNIEJE `shipment` / `shipment_leg` / `terminal`. BRAK tabeli `container`. BRAK `container_type` jako katalogu. GLOSSARY bez `container`.

**Odrzucone:**

- VGM / TARA / waga / objętość Decimal (leftover EXP1).
- `free_time_*` / cutoffy CY/CFS/VGM/SI/AMS (leftover EXP1 / V3).
- `bl_kind` / HBL / MBL / booking_no / live HTTP armatora.
- plomby / PIN (sekret) / reefer min-max.
- `carrier_party_id` / `container_release_party_id` / terminale.
- `shipment_leg_id` / TEU wyliczone / słownik `40'HC`.

## Zakres

1. Migracja `093_container`: RLS, izolacja, indeks `(organization_id, iso_size_type)`, złożone FK do `shipment`.
2. POST/GET. Zła cyfra kontrolna / obcy `iso_size_type` / brak source_ref → 400.
3. UI `/shipments`. `just api-types`. How-to w `katalogi.md` wtopione (40 linii).

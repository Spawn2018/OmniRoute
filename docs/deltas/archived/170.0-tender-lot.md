# Plaster 170.0 · G2.1 `tender_lot`

**Spec źródłowa:** [docs/PLAN-REALIZACJA.md](../../PLAN-REALIZACJA.md) § G2.1 · [karty-pol-g2-tender.md](../../analysis/karty-pol-g2-tender.md) § Dalej `tender_lot`
**Zależy od:** 169.0 `tender` (nagłówek już jest)
**Status:** Zamknięty `/noc` 2026-09-08. Nie auto-award. Nie T-SQL.

## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z G2.1):** jedna tabela `tender_lot` per tenant — **partia przetargu jako dane**, nie korytarz, nie runda i nie kwota. Wiersz = `tender_id` (FK tenanta do `tender`) + `lot_code` (token, nie luźny opis) + `source_ref` (`tenant:manual` albo `fixture://tender-lot/…`). Pusty / zły kod → 400 (detail zawiera `partia`). Obce `source_ref` → 400 (`obce`). GET listy SQL. Serwis nie importuje tenders / quotations / charges / tender_quotes. API składa odczyt nagłówka (`TenderService.get_board`). UI `/tender-lots`. `SHIPPED_CHARGE_ROUTES["170.0"]` = `/tender-lots`. OpenFGA: `can_manage_tender_lots`. Migracja `110_tender_lot`. Marża zostaje na `charge`. Zero Money na tym ekranie.

**Łowca:** ISTNIEJE `tender` — nagłówek sell/buy; **nie** dokładamy partii jako kolumn tam. ISTNIEJE `tender_quote` — ważność + limit; **nie** rozszerzamy. ISTNIEJE `quotation` — wycena; **nie** partia. BRAK `tender_lot`. BRAK `/tender-lots`.

**Odrzucone:**

- `tender_lane` / `tender_round` (leftover G2.2+).
- Data room, matryca Excel (`tender_matrix_cell` z kwotą z P), playbook, four-eyes, win/loss, TED (leftover G2.2–G2.18).
- Auto-award.
- Kwota / marża na tym wierszu.
- Kolumny na `tender`.
- Float / T-SQL / live HTTP.

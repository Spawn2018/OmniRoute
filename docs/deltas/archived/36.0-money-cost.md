## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z Fali 6 M-43):** koszt pieniądza **nie ma tabeli odsetek**. Operator widzi kurs średni NBP (ustawowy fakt) i `buy_amount` z `charge` (gotówka po stronie kupna) — bez mnożenia. Token `money_cost` (UI, nie tabela). Żywy ID **M-43**. 15.0 zostaje tablicą marży/limitu; 6.0 zostaje katalogiem kursu.

**Łowca:** BRAK `interest` / WACC / `money_cost` tabeli. ISTNIEJE: `fetchNbpRates`, `fetchCharges`, `buy_amount`, `<Money/>`, `/nbp-rates`, `/finance`. PODOBNE: 15.0 pokazuje `margin` + NBP; 33.0 pokazuje `sell`.

**Odrzucone:**

- Tabela odsetek / WACC / dni finansowania — zgadywanie schematu (CURRENT).
- Mnożenie `buy × mid` w JS — nie drugi `margin()`; leftover Decimal w SQL.
- `payment_terms_days` w API — kolumna jest, ale nie w kontrakcie HTTP (zgadywanie powierzchni).
- Zapis `nbp_rate` / `charge` z tego ekranu.

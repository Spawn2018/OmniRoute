## Wybrane / odrzucone / dlaczego

**Wybrane (węższe z I3):** jedna tabela katalogu per tenant. Trójka `(trade_side, incoterm, document_kind)` → `recipient_role`. Rodzaje dokumentu = te same tokeny co checklista (`commercial_invoice` | `packing_list` | `bill_of_lading` | `export_declaration`), nie `noted`/`attached`/`other` z `shipment_document`. Rola adresata = role I2 (`shipper` | `consignee` | `origin_agent` | `dest_agent` | `ocean_carrier` | `omni_customs` | `client_customs`). `source_ref` obowiązkowe. Zmiana roli przy tej samej trójce = nowy wiersz + `superseded_by`. GET SQL po parze incoterm×strona (bieżące), opcjonalnie `document_kind`.

UI `/quotations`. `SHIPPED_CHARGE_ROUTES["147.0"]` = `/quotations`. OpenFGA: `can_manage_quotations`. Migracja `087_document_dispatch_rule`.

**Łowca:** ISTNIEJE `document_checklist_rule` — trójka z `mode` → `document_kind` + `blocks_dispatch`; **inny** job (czy dokument jest na liście), nie rozszerzać o adresata. ISTNIEJE `shipment_document.document_kind` (`noted`/`attached`/`other`) — **inny** katalog. ISTNIEJE GLOSSARY `document_dispatch` (wysyłka + `mail_draft`) — leftover. BRAK tabeli `document_dispatch_rule`. BRAK send.

**Odrzucone:**

- Tabela `document_dispatch` (batch mail, `mail_draft_id`, status `draft`/`sent`) — leftover po S11/S18; tu tylko reguła adresata.

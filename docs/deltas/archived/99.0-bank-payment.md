**Status:** Zamknięty `/noc` 2026-09-03. Ten sam żywy ID **M-42**. Nie F9.1.

## Wybrane / odrzucone / dlaczego

**Wybrane:** tabela `bank_payment` per tenant. Operator zapisuje, że ta faktura poszła na ten rachunek (`sales_invoice_id` + `party_bank_account_id` + `source_ref`). Kwoty zostają na `charge`. Tablica 35.0 przestaje udawać, że `sell` + IBAN to płatność. API składa: odczyt faktury, odczyt rachunku, zapis wiersza. Serwis płatności nie importuje `sales_invoices` / `parties` / `charges`. Wiele wierszy na jedną fakturę (rata). Unikat pary `(organization_id, sales_invoice_id, party_bank_account_id)`. Wzorzec jak S36.

**Łowca:** ISTNIEJE 35.0 `/payments` + `fetchBankAccounts` / `fetchCharges` / `sell_amount`. ISTNIEJE 5.0 `party_bank_account` i `iban-lookup`. ISTNIEJE 96.0 `sales_invoice`. BRAK tabeli płatności / SEPA / wyciągu. PODOBNE: 98.0 `quote_invoice_settlement`. Dwa joby (rachunek vs płatność) = `/parties` vs `/payments`.

**Odrzucone:**

- Zostawić tablicę z `charge` — to fundament 35.0, nie żywe M-42.
- Kopia `sell` / marży na wierszu płatności.
- JS odejmujący `sell − zapłacone`.
- SEPA XML / wyciąg / PSD2 / live bank.
- Zapis IBAN z `/payments` — mutacja zostaje na `/parties`.
- Luźny string IBAN zamiast `party_bank_account_id`.
- F9.1.

## Zakres

1. Migracja `057_bank_payment_rls` (po `056_quote_invoice_settlement_rls`): `uq_party_bank_account_org_id` jeśli brak; tabela `bank_payment` z RLS ENABLE+FORCE; FK tenanta do `sales_invoice` i `party_bank_account`.
2. `GET/POST /bank-payments` — OpenFGA `can_manage_bank_payments` = member. POST: `{sales_invoice_id, party_bank_account_id, source_ref}`. Nieznana faktura albo rachunek → 404. Pusty / obcy `source_ref` → 400.
3. UI `/payments`: lista wierszy tabeli + „Zapisz płatność”. `data-bank-payment="board"` zostaje. Lista **nie** idzie z `fetchCharges`. Linki do `/parties` i `/invoices` zostają. `SHIPPED_CHARGE_ROUTES["99.0"]` = `/payments`. Asercje 35.0 bez odejmowania / `parseFloat` / `CatalogCreateForm` zostają; `fetchCharges` na tej tablicy znika.
4. Test izolacji. `just api-types`. How-to `docs/operator/platnosc.md`.

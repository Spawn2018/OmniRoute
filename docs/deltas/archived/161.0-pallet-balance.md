Wiersz = `pallet_kind` (`chep` | `lpr`) + FK złożone do `party` + `unit_count` (integer ≥ 0, sztuka jako dana, nie Decimal pieniędzy) + `source_ref` (`tenant:manual` albo `fixture://pallet-balance/…`). `pallet_kind` spoza allowlisty → 400 (detail zawiera `rodzaj`). `unit_count` ujemny / float / bool → 400 (detail zawiera `sztuk`). GET listy SQL. API składa odczyt `party`; serwis salda nie importuje parties / charges / shipments. UI `/pallet-balances`. `SHIPPED_CHARGE_ROUTES["161.0"]` = `/pallet-balances`. OpenFGA: `can_manage_pallet_balances`. Migracja `101_pallet_balance`. Marża zostaje na `charge`.

**Łowca:** ISTNIEJE `party` — kontrahent, nie saldo palet. ISTNIEJE `container` — ISO 6346, nie paleta. ISTNIEJE `shipment_package` — sztuka na zleceniu, nie Chep. ISTNIEJE `charge` — jedyna marża. ISTNIEJE ⌘K `command-palette` — inny byt „paleta”. BRAK `pallet_balance`. BRAK `/pallet-balances`. BRAK `pallet_kind` chep/lpr.

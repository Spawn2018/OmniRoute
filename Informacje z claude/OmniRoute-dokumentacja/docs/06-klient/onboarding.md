# Wdrożenie klienta

Cel: **od podpisania do pierwszej wyceny w cztery godziny.**
Wdrożenie nie jest usługą — jest funkcją produktu.

## Godzina 1 · Konto

```
□ Utworzenie tenanta, wybór planu
□ Dane firmy pobrane z GUS po numerze NIP
□ Logo, dane rejestrowe, rachunki bankowe
□ Numer polisy OC spedytora, certyfikat AEO jeśli jest
□ Warunki handlowe: OPWS albo własne
□ Pierwszy użytkownik z rolą administratora
```

## Godzina 2 · Dane podstawowe

```
□ Zaproszenie pozostałych użytkowników, przypisanie ról
□ Ustawienie widoczności kosztów per rola
□ Import kontrahentów z pliku, mapowanie kolumn
□ Weryfikacja przez GUS i białą listę
```

## Godzina 3 · Stawki

```
□ Przeciągnięcie plików Excel z cennikami
□ Automatyczne parsowanie
□ Przegląd kolejki akceptacji, poprawki
□ Zatwierdzenie
```

To jest moment, w którym klient widzi wartość produktu.

## Godzina 4 · Pierwsza wycena

```
□ Wprowadzenie realnego zapytania
□ Wycena na własnych stawkach klienta
□ Konfiguracja szablonu oferty: logo, stopka, warunki
□ Wysłanie testowej oferty na własny adres
```

## Tydzień 1 · Uruchomienie

```
□ Podłączenie skrzynki pocztowej
□ Konfiguracja reguł marży
□ Import katalogu agentów z sieci
□ Pierwsze zapytanie do agentów przez system
□ Rozmowa kontrolna po pięciu dniach
```

## Miesiąc 1 · Pogłębienie

```
□ Podłączenie poświadczeń armatorów
□ Tracking pierwszych zleceń
□ Konfiguracja KSeF
□ Przegląd pierwszych wskaźników
□ Rozmowa o kolejnych modułach
```

## Mierniki wdrożenia

| Miernik | Cel |
|---|---|
| Czas do pierwszej wyceny | poniżej 4 godzin |
| Liczba stawek w bazie po tygodniu | powyżej 200 |
| Pierwsze zapytanie do agenta | do 7 dni |
| Aktywni użytkownicy po miesiącu | powyżej 80% zaproszonych |

Klient, który po miesiącu nie wystawił dziesięciu ofert, jest zagrożony
odejściem. Wskaźnik kondycji wychwytuje to automatycznie.
